## **一、深度学习 与 传统机器学习**

​		你正在教一个孩子识别猫和狗。传统的方法可能是：你拿出一本图画书，指着图片说这是猫，它有尖耳朵、胡须和一条长尾巴；这是狗，它的耳朵可能下垂，鼻子更长。你是在明确地告诉孩子区分两者的**规则和特征**。

​		而另一种方法则是：你给孩子看成千上万张猫和狗的图片，只是简单地告诉每张图片是猫还是狗。经过足够多的观察，孩子的大脑自己会总结出猫和狗那些难以言喻的、复杂的区别特征，比如毛发的纹理、眼睛的神态、身体的轮廓。这种方法更接近于**让数据自己说话**。

**“机器学习 ≠ 深度学习”**

| 分类角度   | 说明                                                     |
| :--------- | :------------------------------------------------------- |
| 📚 学科结构 | 深度学习是机器学习的一个子领域                           |
| 🧰 工具方法 | 机器学习包括许多经典算法，而深度学习只是一类方法         |
| 💻 应用方式 | 机器学习适合小数据、结构化；深度学习适合大数据、非结构化 |
| 🧪 实际开发 | 很多工程用的是 XGBoost、LightGBM、SVM，不涉及神经网络    |

| 数据场景(算法差异) | 适合技术 |
| :----------------- | :------- |
| 小数据、结构化     | 机器学习 |
| 大数据、图像/文本  | 深度学习 |
| 要求可解释性强     | 机器学习 |
| 可牺牲透明度换性能 | 深度学习 |

**核心区别**

| 维度             | 机器学习（ML）                      | 深度学习（DL）                    |
| :--------------- | :---------------------------------- | :-------------------------------- |
| **定义**         | AI 的一种实现方式，依赖人工特征设计 | ML 的子集，基于多层神经网络       |
| **特征提取**     | 手动提取：人定义哪些数据重要        | 自动提取：模型自动挖掘深层特征    |
| **模型结构**     | 浅层模型（线性回归、SVM 等）        | 多层模型（CNN、RNN、Transformer） |
| **训练数据量**   | 千级~万级即可表现良好               | 通常需十万~百万级样本             |
| **计算资源**     | 要求低，适合普通CPU                 | 高性能GPU或TPU更适合              |
| **训练时间**     | 较快，调参少                        | 慢，需要大规模计算和调参          |
| **适用数据类型** | 结构化数据（如表格、数值）          | 非结构化数据（图像、文本、语音）  |
| **可解释性**     | 高，模型容易理解                    | 低，通常被视为“黑箱”              |

## 二、**有监督学习**

​		f(x)=ωx+b，我们通过模型输入 x，得到预测输出y^ ，然后通过比较标签y 和y^的差异情况，来调节模型的权重 ω，最终使模型达到或趋近观测情况的建模过程。

**缺点：**因为要求训练数据都是有标注的，而数据标注成本往往十分巨大，这是因为基本上数据标注都是人手工标注，数据标注花费的人力、物力、财力不是普通组织和个人所能承担。这导致对于大多数公司、个人、学校甚至研究机构来说，可应用范围受限，从事「机器学习」方面的组织和个人，于是只能通过仅有的开源 数据集调试、训练自己的模型。

## **三、线性回归**

![image-20260726174949244](https://gitee.com/MaGL/typorapic/raw/master/20260726174949324.png)

**1、核心概念：什么是“拟合”？**

​		“拟合”是指通过调整模型中的未知参数（如直线的斜率和截距），使得模型函数（这里是直线）与已知的离散数据点集之间的差别（误差）达到最小。

​		**拟合的本质**：不是让直线穿过每一个点（这在现实中几乎不可能），而是找到一条“最优”的直线，使得所有数据点到这条直线的某种“距离”总和最小。

​		**最优标准（最小二乘法）**：在线性回归中，最常用的评判标准是**普通最小二乘法（OLS）**。它的核心思想是：寻找一条直线，使得所有观测点到该直线在垂直方向（Y轴）上的偏差（即**残差**，真实值减去预测值）的平方和最小。公式表达为最小化 $ Q = \sum_{i=1}^n (y_i - \hat{y}_i)^2 $，其中 $y_i$ 是真实值，$\hat{y}_i$是预测值。

**2、线性回归的模型形式**

​		在二维空间中，线性回归的模型通常被表示为：	$\hat{y}=wx+b$

​		**w（斜率/权重）**：表示自变量 x 每增加一个单位，因变量 y 平均变化多少。

​		**b（截距）**：表示当 x=0 时，y 的预测值，负责调整直线的上下位置。

​		**$\hat{y}$（拟合值/预测值）**：根据直线方程计算出的理论值，对应图中回归线上的点。

3、拟合过程与求解方法

​		图中从左图到右图的箭头，代表了模型训练的求解过程。计算机如何通过算法找到这条最佳回归线呢？主要有以下几种方法：

​		正规方程法（Normal Equation）：直接通过数学公式（矩阵运算）一步求解出最优参数 w 和 b。公式为 $\beta = (X^T X)^{-1} X^T y$  ，这种方法在小规模数据上非常快速准确。

​		梯度下降法（Gradient Descent）：当数据量极大时，正规方程计算量太大。梯度下降法则通过不断迭代，沿着损失函数（如均方误差）下降最快的方向（梯度反方向）逐步调整 w 和 b 的值，直到找到最小值。

![image-20260726180704164](https://gitee.com/MaGL/typorapic/raw/master/20260726180704272.png)

4、**回归线表达式（True regression line）**

​		直线方程为 $y = \beta_0 + \beta_1 x$

​		y：因变量（目标值）；x：自变量（特征）；$β_0$：截距，表示直线与 y 轴的交点；$β_1$：斜率，表示 x 每增加1个单位，y 的变化量。

​		在实际应用中，我们用样本数据估算出的参数通常记作 $\hat{β_0}$ 和 $\hat{β_1}$，计算出的预测值记作 $\hat{y}$	

5、**误差项（ε）与残差**

​		ε1 和 ε2，它们代表**真实观测值**与**回归线预测值**之间的垂直距离。

​		在统计学中，这个差值被称为**残差（Residual）**，公式为 $ e_i = y_i - \hat{y}_i $

​		在理论模型中，它被称为**误差项（Error Term）**，反映了模型未能捕捉到的随机因素或噪声

​		真实数据点 $(x_1,y_1)$ 和 $(x_2,y_2)$ 因为各种随机原因，通常不会完美落在直线上，这些散落的点与直线之间的缝隙就是误差的体现

6、**损失函数（MSE）**

​		衡量模型预测偏差的量化指标——**均方误差（Mean Squared Error, MSE）**

​										$ MSE = \frac{1}{n} \sum_{i=1}^{n} (Y_i - \hat{Y}_i)^2 $

​		$ Y_i $：第 \( i \) 个样本的真实值。

​		$ \hat{Y}_i  $：第 \( i \) 个样本的预测值（由左侧的回归方程计算得出）。

​		$Y_i - \hat{Y}_i $： 即单个样本的误差（残差）。

​		$ (\ldots)^2 $： 对误差进行平方处理。这一步非常关键：首先，平方消除了正负号（避免上方的正误差和下方的负误差相互抵消）；其次，平方会放大较大的误差，使得模型对"离谱"的预测更加敏感。

​		$  \sum_{i=1}^n$ ： 将所有样本的平方误差求和。

​		$ \frac{1}{n} $： 求平均值，得到"均方"误差。

7、**两者的联系与模型训练目标**

​		表达式是**“假设空间”**（模型能长什么样），损失函数是**“评判标准”**（模型好不好）。

​		**训练过程**：线性回归的模型训练（如上一轮提到的梯度下降或正规方程），本质上就是在不断调整 β0 和 β1 的值，使得计算出的 MSE 尽可能小。

​		**目标**：当 MSE 达到最小值时，我们就找到了那条“最优”的回归线（即最小二乘法所求解的直线）。此时，所有数据点到这条直线的垂直距离（残差）的平方和最小。

**8、MSE 的局限性与拓展**

虽然 MSE 是最常用的损失函数，但它也有明显的特性：

​		**对异常值敏感**：因为平方放大的效应，如果数据集中有几个偏离很远的异常点，MSE 会变得非常大，从而主导整个模型的参数调整方向，导致模型为了迁就这几个点而偏离整体趋势。

​		**单位问题**：MSE 的单位是原始数据单位的**平方**（例如预测房价，单位是“元”，MSE 单位就是“元²”），不够直观。为了解决这个问题，实际应用中常使用它的平方根——**均方根误差（RMSE）**。

​		**替代方案**：如果对异常值不敏感，或者希望模型更稳健，有时会选择**平均绝对误差（MAE, Mean Absolute Error）**，即直接求误差的绝对值的平均，公式为 $ MAE = \frac{1}{n} \sum |Y_i - \hat{Y}_i| $

![image-20260726180737853](https://gitee.com/MaGL/typorapic/raw/master/20260726180737963.png)

**9、多元线性回归**

​		**模型表达式**：$ z = \beta_0 + \beta_1 x + \beta_2 y $   ，两个自变量 x 和 y，模型试图用一个平面去“最好地”逼近三维空间中的散点数据。

​		**核心思想**：在三维空间中，用一个平面去拟合数据。目标是最小化所有数据点到该平面的距离（通常是垂直距离）的平方和。

**10、从“线”到“面”的扩展：高维推广**

​		简单线性回归：1个输入特征 → 2维空间 → 拟合**直线**

​		多元线性回归：2个输入特征 → 3维空间 → 拟合**平面**

​		**k个输入特征** → **(k+1)维空间** → 拟合**超平面（Hyperplane）**，例如，如果有3个特征，就在4维空间中拟合一个“超平面”，人类无法直观画出，但数学上完全可行。

​		**数学形式统一**：$ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_k x_k $ ；y：因变量（目标）；$x_1,x_2,…,x_k$：k 个自变量（特征）；$β_0,β_1,…,β_k$：待求的参数（权重）。

​		**向量形式**：$y=Xβ$，其中 X 是设计矩阵（包含常数项1和所有特征），β 是参数向量

**11、多元线性回归中残差与损失函数的一致性**

​		在多元回归中，残差仍然是“真实值 - 预测值”，即 $ e_i = y_i - \hat{y}_i $。在三维图中，就是数据点到平面的垂直距离（在目标变量轴上的投影）

​		**损失函数**：依然是**均方误差（MSE）**，只是现在是对所有样本、所有维度的残差平方求平均:

​			$ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $      这里的 $y_i$和 $\hat{y_i}$ 都是标量（即使输入是多维的，输出仍是标量。

| **特征**   | **简单线性回归**   | **多元线性回归**      |
| :--------- | :----------------- | :-------------------- |
| 输入特征数 | 1                  | ≥2                    |
| 空间维度   | 2维（x-y）         | 3维及以上（x-y-z...） |
| 拟合对象   | 直线               | 平面（或超平面）      |
| 模型表达式 | y=β0+β1x           | y=β0+β1x1+⋯+βkxk      |
| 残差       | 点到直线的垂直距离 | 点到平面的垂直距离    |
| 损失函数   | MSE                | MSE                   |
| 优化目标   | 最小化 MSE         | 最小化 MSE            |
| 应用场景   | 单因素分析         | 多因素综合分析        |

| :------------- | :----------- | :------- | :------------- | :------- |

​		公式$ y = \alpha + \beta_1(x_1) + \beta_2(x_2) + \cdots + \beta_n(x_n) $是多元线性回归的核心模型，它将表格的特征与预测目标联系了起来。

​		**y**：代表预测的因变量，即表格的 价格。

​		**α（Alpha）**：标注为 **Bias（偏置/截距）**。它类似于一元回归中的截距 b，表示当所有特征取值为0时，价格的基准预测值。

​		**$x_1,x_2,…,x_n$**：代表各个**特征（Feature）**。例如$x_1$ 可以是处理器速度，$x_2$ 是屏幕尺寸，以此类推。

​		**$β_1,β_2,…,β_n$**：代表各个特征对应的**权重（Weight）**。这是模型需要学习的参数，反映了每个特征对预测结果的“影响力”大小。例如，如果 $β_1$ 很大，说明处理器速度对价格的影响非常显著。

​		**预测值（Predicted value）**：整个公式计算出来的结果，也就是模型对这台笔记本价格的预测。

​		**均方误差（MSE）** 公式：$ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $，这强调了无论特征有多少个，评估模型好坏的标准依然不变。

**真实值与预测值的差距**：$(Y_i−\hat{Y_i})$。在笔记本电脑的例子中，就是表格里的真实售价$Y_i$减去模型预测出的售价$\hat{Y_i}$。

**优化目标**：模型训练的过程，就是通过算法（如梯度下降或正规方程）不断调整 α 和 β 的值，使得所有样本的这个误差平方和的平均值（MSE）最小。也就是让预测的价格尽可能逼近真实的售价。

## **四、梯度下降与模型训练**

![image-20260726180904232](https://gitee.com/MaGL/typorapic/raw/master/20260726180904330.png)

**1、梯度下降**

​		**梯度下降（Gradient Descent）**是机器学习和深度学习中**最基础、最核心的优化算法**。它的终极目标是：**通过调整模型的参数，让“损失函数（Cost/Loss）”的值变得越来越小**，从而让模型预测得更准。

**2、直观的“下山”过程**

二维坐标系非常生动地描绘了梯度下降的寻找最优解的过程：

​		**横轴 (Weight)**：代表模型的一个参数（比如权重 w）。你可以把它理解为“下山的人当前所处的位置”。

​		**纵轴 (Cost)**：代表“损失函数”的值，即模型预测的误差。你可以把它理解为“当前的海拔高度”。我们的目标是让 Cost 越小越好，也就是走到海拔最低的山谷。

​		**黑色圆点 (Initial Weight)**：这是**初始权重**。在训练开始时，我们通常不知道哪里是最低点，所以会随机选择一个起始位置（相当于把你随机扔到山上）。

​		**黑色虚线与 Gradient (梯度)**：虚线是经过黑点的切线。**梯度就是这条切线的斜率**。在数学上，它等于损失函数对权重的导数。梯度的方向指向函数值**上升最快**的方向。如果切线很陡（斜率大），说明离谷底还很远；如果切线很平（斜率接近0），说明快到谷底了。	

​		**Incremental Step (增量步长)**：图中沿着曲线向下的黑色小箭头，代表模型在每一次迭代中迈出的“步子”。你会发现，刚开始坡度陡（梯度大）的时候，步子迈得比较大；越靠近底部，坡度变缓（梯度变小），步子自然就变小了。

​		**Minimum Cost (最小代价)**：曲线的最底端。此时导数为0，意味着无论往左还是往右走，Cost 都会增加。模型训练完成，找到了最优参数。			

**3、核心数学公式**

​		梯度下降最核心的**参数更新公式**： $w_i := w_{i-1} - \eta \nabla Q_i(w) $

​		**$w_{i-1}$（previous weight）**：更新前的旧参数（对应图中的“Initial Weight”）。

​		**$w_i$（new weight）**：更新后的新参数（迈完一步后到达的新位置）。

​		**η（learning rate，学习率）**：这是一个非常重要的超参数，控制着我们每一步迈多大（步长）。η 太小会导致收敛极慢（蜗牛下山）；η 太大会导致步子太大，可能直接跳过最低点甚至发散。

​		**$∇Q_i(w)$（gradient of the loss function，损失函数的梯度）**：即在当前参数 w 处计算出的损失函数的偏导数（对应图中的“Gradient”）。它告诉我们要往哪个方向走才能最快上升。

​		**为什么是“减号”？**：因为梯度 $∇Q_i(w)$指向的是损失函数**上升最快**的方向，而我们的目的是**最小化**损失，所以必须朝着梯度的**反方向**（负梯度）走，也就是公式中的**减去**梯度。

**4、梯度下降的完整运作流程**

梯度下降的运作过程可以总结为以下四步：

​		**初始化**：随机选择一个初始的参数 w（扔到山上）。

​		**计算梯度**：在当前位置 w，计算损失函数对 w 的梯度 ∇Qi(w)（感受脚下的坡度）。

​		**更新参数**：按照公式 w:=w−η∇Qi(w) 更新参数（朝着最陡的下坡方向迈出一步）。

​		**重复迭代**：不断重复步骤2和3，直到梯度接近0（到达平地）或者损失函数不再明显下降，此时认为算法收敛，找到了最优参数。

![image-20260726180941544](https://gitee.com/MaGL/typorapic/raw/master/20260726180941723.png)

**5、$\nabla Q_i(w)$是什么**

​		$\nabla Q_i(w)$ 表示第 **i** 个样本的损失函数对参数 **w** 的梯度，即：$ \nabla Q_i(w) = \frac{\partial Q_i(w)}{\partial w} $

​		其中：

​				$\nabla Q_i(w)$ 是模型在第 **i** 个样本上的损失值（如均方误差、交叉熵等）

​				$\nabla$是对参数 w 求偏导数的算子

​				结果是一个**向量**，每个分量对应一个参数的偏导数，表示"该参数变化一点点时，损失变化多少"

​		**怎么求$\nabla Q_i(w)$**

​				一个简单的例子说明。假设：

​						模型：$y=w⋅x+b$（单参数 w，偏置 b）

​						损失函数（均方误差）：$ Q_i(w) = \frac{1}{2}(w \cdot x_i - y_i)^2 $

​				**对 w求偏导**（链式法则）：$ \frac{\partial Q_i}{\partial w} = (w \cdot x_i - y_i) \cdot x_i $

​				**对 b求偏导**：$ \frac{\partial Q_i}{\partial b} = (w \cdot x_i - y_i) \cdot 1 $

​				所以该样本的梯度向量为：
$$
\nabla Q_i(w) =
\begin{bmatrix}
\frac{\partial Q_i}{\partial w} \\
\frac{\partial Q_i}{\partial b}
\end{bmatrix}
$$
​		**梯度下降具体计算示例：**

​					场景设定：

​							模型：$\hat{y} = w \cdot x + b $

​							损失函数：$Q(w,b) = \frac{1}{2}(w \cdot x + b - y)^2$

​							样本：$x = 2， y = 10$

​							初始参数：$w = 1, b = 0 $

​							学习率：$\eta = 0.01$

​					第一步：前向传播，算损失

​							$ \hat{y} = w \cdot x + b = 1 \times 2 + 0 = 2 $

​							$ Q = \frac{1}{2}(2 - 10)^2 = \frac{1}{2} \times 64 = 32 $

​					第二步：求两个梯度 ∇Q

​							现在有两个参数 w 和 b，需要分别求偏导，用**链式法则**：

​									**对 w 求偏导：**$\frac{\partial Q}{\partial w} = (w \cdot x + b - y) \cdot x = (2 - 10) \times 2 = -16$

​									**对 b 求偏导：**$ \frac{\partial Q}{\partial b} = (w \cdot x + b - y) \cdot 1 = (2 - 10) \times 1 = -8 $
$$
\nabla Q = 
\begin{bmatrix}
\frac{\partial Q}{\partial y} \\
\frac{\partial Q}{\partial b}
\end{bmatrix}
=
\begin{bmatrix}
-16 \\
-8
\end{bmatrix}
$$
​					第三步：梯度下降更新
​							两个参数**同时更新**：

​								$ w_{\text{new}} = w - \eta \cdot \frac{\partial \mathcal{Q}}{\partial w} = 1 - 0.01 \times (-16) = 1 + 0.16 = 1.16 $

​								$ b_{\text{new}} = b - \eta \cdot \frac{\partial \mathcal{Q}}{\partial b} = 0 - 0.01 \times (-8) = 0 + 0.08 = 0.08 $

​					第四步：验证损失是否下降

​								$ \hat{y}_{\text{new}} = 1.16 \times 2 + 0.08 = 2.40 $

​								$ Q_{\text{new}} = \frac{1}{2}(2.40 - 10)^2 = \frac{1}{2} \times 57.76 = 28.88 $

​								损失从 **32 → 28.88**，确实下降了。

| 迭代步 | w         | b         | y          | 损失 Q   |
| ------ | --------- | --------- | ---------- | -------- |
| 0      | 1.000     | 0.000     | 2.000      | 32.00    |
| 1      | 1.160     | 0.080     | 2.400      | 28.88    |
| 2      | 1.312     | 0.156     | 2.780      | 26.06    |
| 3      | 1.456     | 0.228     | 3.141      | 23.53    |
| ...    | ...       | ...       | ...        | ...      |
| ∞      | **5.000** | **0.000** | **10.000** | **0.00** |

最终收敛到 $w=5, b=0$，满足 $2w+b=10$，损失降为 **0**。

**6、梯度下降衍生**

根据每次计算梯度时所使用的数据量不同，梯度下降还衍生出了三种常见的变体：

​		 **批量梯度下降 (Batch GD)**：每次用**全部**训练数据计算梯度。稳定但计算量大。	

​				它的梯度计算逻辑是‌**遍历全部训练集的所有样本**‌，累加所有样本的损失梯度后取平均，再执行一次参数更新：

​													$ w = w - \eta \cdot \frac{1}{N} \sum_{i=1}^N \nabla Q_i(w) $

​				优势：梯度方向是全局最准确的，更新过程非常平稳，能稳定收敛到全局最优（凸损失场景下）

​				劣势：如果训练集规模达到几十万、上百万级别，单次迭代就要加载全量数据计算，算力开销极大，甚至无法在常规硬件上运行，也不支持在线流式数据更新。

​		**随机梯度下降 (SGD)**：每次只用**一个**随机样本计算梯度。速度快但有震荡。

​				它完全放弃了全量数据，‌**每一次更新只随机抽取1个样本**‌，直接用这个单样本的梯度来更新参数：

​														$ w = w - \eta \cdot \nabla Q_i(w) $

​				优势：单次迭代计算量极小，更新速度极快，还能在流式到达的新数据上实时更新模型，同时梯度自带的随机震荡，有概率帮模型跳出局部最优解

​				劣势：单样本的梯度噪声极大，更新路径全程剧烈震荡，即使逼近最优解也很难完全收敛到最优点，会在极小值附近持续来回跳动。

​		**小批量梯度下降 (Mini-batch GD)**：每次用**一小批**样本计算梯度。结合了前两者的优点，是深度学习中最常用的形式。

​				每次从全量数据里随机抽取一小批（通常是32/64/128个样本，称为一个batch），用这组样本的平均梯度来更新参数：

​														$ w = w - \eta \cdot \frac{1}{B} \sum_{i=1}^B \nabla Q_i(w) $

​				优势：既把单次迭代的计算量控制在了硬件可轻松承载的范围，又通过小批量平均大幅压低了单样本梯度的噪声，更新过程足够平稳，同时保留了一定的随机震荡，帮助模型避开局部最优，兼顾了训练效率和收敛质量。

​				几乎所有现代深度学习框架的默认训练逻辑，都是基于小批量梯度下降来实现的。

**1、什么是“升维”？**

​		在机器学习中，“升维”通常指：**增加模型的表达能力（capacity）**，比如，增加多项式次数（多项式回归）、增加神经网络的层数或神经元数量（深度学习）、引入交叉特征、核技巧（SVM）、嵌入层（NLP）等，本质上，是在**特征空间中进行扩展**，让模型能拟合更复杂的模式。

**2、为什么不能无限升维？**

​		**过拟合风险**：模型太复杂 → 记住噪声 → 泛化差

​				**现象**：模型在训练集上表现完美（损失趋近于0），但在测试集或新数据上表现极差。

​				**本质**：模型复杂度过高时，会“记住”训练样本中的**噪声和异常值**，而不是学习通用的数据规律。

​				**后果**：泛化能力急剧下降，模型失去预测意义。

​				即：模型“背题”而非“学知识”。

​		**计算成本上升**：参数量激增 → 训练慢、内存占用高

​				**参数数量**：特征维度从 d 升到 D （ D≫d ），参数总量急剧膨胀（尤其在多项式回归、神经网络中）。

​				**具体影响**：训练时间大幅增加；内存/显存消耗飙升；梯度计算、矩阵求逆等操作难以承受

​		**可解释性下降**：黑盒化严重（尤其是深度学习）

​				**模型透明度**：特征维度越高，各特征对输出的贡献越难以理解。

​				**黑盒化**：尤其在深度学习（如CNN、Transformer）中，即使知道输入维度极高，也很难解释模型“为什么”做出某种决策。

​				**对应用场景的限制**：在金融、医疗、司法等对解释性要求极高的领域，这种“黑盒”特性可能是致命的。

| 问题     | 对应方法                                          |
| :------- | :------------------------------------------------ |
| 过拟合   | 正则化（L1/L2）、早停法、交叉验证、Dropout        |
| 计算成本 | 降维（PCA、t-SNE）、特征选择、轻量化模型设计      |
| 可解释性 | 使用可解释模型（线性回归、决策树）、SHAP/LIME分析 |

![image-20260726181051961](https://gitee.com/MaGL/typorapic/raw/master/20260726181052079.png)

**3、三种拟合状态详解**

​		**欠拟合（Underfitted）—— High bias error（高偏差误差）**

- 模型**过于简单**，无法捕捉数据中的真实规律
- 偏差（Bias）高，意味着模型的预测均值与真实值之间有系统性偏离
- 典型表现：无论训练集还是测试集，误差都很大
- 常见原因：模型复杂度不够、特征不足、训练不充分

​		**良好拟合 / 鲁棒（Good Fit / Robust）—— Balance between bias and variance（偏差与方差之间的平衡）**

- 偏差和方差之间达到了**平衡**
- 模型复杂度适中，既学到了数据的真实规律，又没有拟合噪声
- 训练集和测试集上的表现**都较好且接近**
- "Robust"一词意味着模型具有**鲁棒性**——面对新数据或微小扰动时，表现依然稳定

​		**过拟合（Overfitted）—— High variance error（高方差误差）**

- 模型**过于复杂**，把训练数据中的噪声也当成了规律
- 方差（Variance）高，意味着模型对不同训练数据的微小变化**非常敏感**
- 典型表现：训练集上表现极好，但测试集上表现**大幅下降**

**4、偏差与方差的核心矛盾**

|      | 增加模型复杂度 | 减少模型复杂度 |
| ---- | -------------- | -------------- |
| 偏差 | 降低           | 升高           |
| 方差 | 升高           | 降低           |
| 结果 | 可能过拟合     | 可能欠拟合     |

​		总误差的数学分解：$总误差=偏差^2+方差+不可约误差（噪声）$

**5、常见解决方法**

**过拟合**

| 方法                   | 原理                                               |
| ---------------------- | -------------------------------------------------- |
| 正则化（L1/L2）        | 在损失函数中加惩罚项，限制参数大小，降低模型复杂度 |
| Dropout                | 训练时随机关闭部分神经元，避免对特定特征过度依赖   |
| 增加训练数据           | 数据越多，模型越难记住噪声，被迫学习真正的规律     |
| 数据增强               | 通过翻转、旋转、裁剪等方式扩充数据                 |
| 早停（Early Stopping） | 监控验证集误差，当其不再下降时停止训练             |
| 减少模型复杂度         | 减少层数、减少参数量                               |

**欠拟合**

| 方法           | 原理                     |
| -------------- | ------------------------ |
| 增加模型复杂度 | 加层数、加参数           |
| 增加特征       | 引入更多与目标相关的信息 |
| 减少正则化     | 放松对参数的约束         |
| 训练更久       | 可能是训练尚未收敛       |

**6、为什么用"偏差"和"方差"来描述欠拟合与过拟合**

​		**偏差（Bias）：**模型预测的**平均值**和真实值之间的**系统性**差距，即 $ E[\hat{y}] - f(x) $ 。它衡量"模型平均下来离真相有多远"。

​		**方差（Variance）：**换不同训练集时，模型预测值**围绕它自己平均值的抖动**，即 $ E[(\hat{y} - E[\hat{y}])^2] $。它衡量"模型对训练数据有多敏感"。

​		**为什么欠拟合叫"高偏差"：**一个欠拟合的模型，比如用直线拟合曲线数据（$ \hat{y} = w_1x + w_0 $），不管你用什么训练数据去训练它，它出来的**永远是一条直线**。

​				$$ \hat{y} = w_1x + w_0 $$是一元线性回归模型，属于一次函数形式。在二维平面中，一次函数的几何图形就是一条直线。模型训练过程本质上是通过训练数据来调整参数$w_1$（斜率）和$w_0$（截距），但这些参数的调整只能改变直线的倾斜程度（斜率$w_1$）和在 y 轴上的截距位置（截距$w_0$），无法改变模型本身一次函数的形式，所以无论使用何种训练数据进行训练，最终得到的预测结果对应的图形始终是一条直线。

​				如果你换 100 组不同的训练数据，训练出 100 个模型，这 100 个模型的预测**几乎一模一样**（都是差不多的直线），所以**方差很低**（结果稳定）；但**每一条直线都离真实曲线很远**，所以**偏差很高**

​		**为什么过拟合叫"高方差"：**一个过拟合的模型，比如用极高次多项式拟合（$ \hat{y} = w_1x + w_2x^2 + w_3x^3 + \cdots + w_nx^n $）。

​				如果你换 100 组不同的训练数据，训练出 100 个模型，每个模型都**完美地穿过了各自的训练点**，但因为训练数据略有不同，这 100 个模型的形状**差异巨大**，所以**方差很高**（结果极不稳定），虽然在各自的训练集上偏差很低，但对新数据来说，预测**忽高忽低**。

![image-20260726181112746](https://gitee.com/MaGL/typorapic/raw/master/20260726181112807.png)

**横轴（Epochs）**：代表模型训练的轮次。随着轮次增加，模型不断迭代参数。

**纵轴（Loss）**：代表模型预测值与真实值之间的误差。

**蓝色曲线（Training Loss）**：训练损失。随着训练进行，它单调递减，说明模型在训练集上的拟合程度越来越高。

**橙色曲线（Validation Loss）**：验证损失。它衡量模型在未见过的验证集上的泛化能力。这条曲线呈现先下降后上升的“U”型。

**虚线与箭头（Early Stopping Point）**：这是整张图的灵魂。它表示当验证损失（橙色曲线）达到最低点（谷底）并开始回升时，立即停止训练，并将此时的模型参数作为最终模型。

**7、什么是 Early Stopping**

​		Early Stopping 是一种在模型训练过程中**提前终止训练**的策略，用于防止过拟合。核心思想很简单：**不是训练越久越好**。

​		Early Stopping 本质上是一种**用时间换泛化**的策略——与其让模型训练到收敛（可能已经过拟合），不如在验证误差最佳时及时停止，保留模型对新数据的泛化能力。它简单、高效，是实际深度学习中最常用的正则化手段之一。

![image-20260726181133001](https://gitee.com/MaGL/typorapic/raw/master/20260726181133089.png)

 **原始 3D 空间** -> **降到 2D —— “恰到好处”** -> **降到 1D —— “压过头了”**

**8、什么是降维，为什么需要它**

​		**降维**指把一个 D*D* 维的样本 $ x \in \mathbb{R}^D $通过映射 f*f* 变换到低维表示 $ \mathbf{z} \in \mathbb{R}^d \quad (d \ll D) $，同时**尽可能保留对任务有用的结构**（方差、距离、邻域、类别边界、流形形状等）。

​		在高维数据中，往往会遇到“**维度灾难**”（Curse of Dimensionality），因此我们需要降维：

​				**去除冗余，减少计算量**：特征太多会导致模型训练极慢，且占用大量内存。降维可以减少特征数量，加快训练和		预测速度。

​				**去除噪声，防止过拟合**：高维数据中可能包含很多无关紧要甚至干扰的噪声特征。降维可以提取出最核心的主成		分，让模型泛化能力更强。

​				**可视化**：人类最多只能直观理解三维及以下的数据。为了看懂复杂数据，必须把它降到2D或3D画成散点图（如		中间那张图），从而发现数据的潜在结构。

​				**消除多重共线性**：很多时候特征之间是相互关联的（比如“身高(cm)”和“身高(m)”），降维可以把这些相关的特		征合并成独立的新特征。

​		**维度灾难：**当数据的维度增加时，所需的数据量呈指数级增长**，导致许多在低维空间中行之有效的算法在高维空间中变得不可行。

​				**空间急剧膨胀**：

| 维度   | 覆盖 [0,1] 区间需要的等距点数                                |
| ------ | ------------------------------------------------------------ |
| 1 维   | 10（在1维的直线上，覆盖 [0,1] 区间需要10个等距点。例如在数轴上 [0,1] 区间上均匀分布10个点，每个点间距为0.1） |
| 2 维   | 10² = 100                                                    |
| 10 维  | 10¹⁰ = 100亿                                                 |
| 100 维 | 10¹⁰⁰（超过宇宙原子总数）                                    |


​				**距离度量失效**

​						假设你随机在空间里取两个点，算它们的欧氏距离：$ d = \sqrt{(x_1 - y_1)^2 + (x_2 - y_2)^2 + \cdots + (x_D - y_D)^2} $

​						每一维都贡献一点"距离"。当维度 D很大时：维度多了，**最近的点和最远的点的距离差距变得微不足道**，所				有点对之间的距离都趋向于**同一个值**。

​						当维度D不断升高时，所有维度的差值平方的平均占比会被摊薄，单个维度的占比会变得极低。这就导致没				有任何一个维度的差异能主导总距离，所有点对的总距离都围绕全局平均值小幅波动，最终出现高维下距离区分				度失效的现象。

**9、两种最经典的线性降维方法**

​		**PCA（主成分分析）—— 无监督的“方差最大化”**

​				**核心思想**：PCA 是一种**无监督学习**算法，它在降维时**完全不考虑数据的类别标签**。它的唯一目标是找到数据变		化最大的方向（主成分），并将数据投影过去，从而保留尽可能多的原始信息（方差）。

​		**LDA（线性判别分析）—— 有监督的“类间最大化”**

​				**核心思想**：LDA 是一种**有监督学习**算法，它在降维时**必须依赖数据的类别标签**。它的核心目标是寻找一个投影		方向，使得**不同类别的数据点尽可能分离（最大化类间距离），而同一类别的数据点尽可能聚集（最小化类内距离）**。

| **对比维度**     | **PCA (主成分分析)**                           | **LDA (线性判别分析)**                                   |
| :--------------- | :--------------------------------------------- | :------------------------------------------------------- |
| **学习类型**     | **无监督**（不需要类别标签）                   | **有监督**（必须提供类别标签）                           |
| **优化目标**     | 最大化数据的**整体方差**（保留最多信息）       | 最大化**类间距离**，最小化**类内距离**（提升类别可分性） |
| **投影方向**     | 数据变化最大的方向（如左图的 λ1）              | 最能区分不同类别的方向（如右图的水平轴）                 |
| **降维维度限制** | 无限制（可降至任意维度，只要不超过原始特征数） | 最多降至 **类别数 - 1**（例如只有2类，最多只能降到1维）  |
| **适用场景**     | 数据去噪、特征压缩、高维数据可视化（无标签时） | 分类任务前的特征提取、有标签数据的判别分析               |

​		**举例理解：**用一个生活中的**“学生综合评价”**例子来模拟这两种算法的行为。

​				假设我们要评价一群学生，有两个特征（维度）：

​				- **X1：熬夜程度**（1-10分，越晚睡分数越高）

​				- **X2：打游戏时长**（1-10小时，时间越长分数越高）

​				我们观察到数据呈现很强的相关性：熬夜的通常也打游戏多。

​		**PCA（主成分分析）的应用：**

​				校长想知道学生的“夜生活活跃度”整体分布情况，但他不想看两个乱七八		糟的图表，想合成一个指标。他**不在乎**谁是学霸谁是学渣（无监督）。

​				PCA 会发现 X1（熬夜）和 X2（打游戏）是高度正相关的，数据点大致分		布在一条从“左下（早睡少玩）”到“右上（晚睡多玩）”的斜线上。

- **它寻找方向**：它会画一条贯穿这条斜线的新轴（主成分），这个方向上数据的**跨度最大**（方差最大）。

- **新指标**：PCA 会将“熬夜”和“打游戏”合成一个叫**“夜猫子指数”**的综合得分。

- **结果**：得分高的人：可能是熬夜打游戏的学生，也可能是单纯失眠的学生，还可能是通宵学习的学生（只要在这个方向上投影远）。

- **特点**：它只保留了数据的**整体结构**，丢失了具体的物理意义，也没区分好坏。

  ![image-20260731150339134](https://gitee.com/MaGL/typorapic/raw/master/20260731150339202.png)

​		**LDA（线性判别分析）的应用：**

​				教务处想筛选出“需要干预的问题学生”（标签：坏学生 vs 好学生），以		便进行针对性辅导。他们手头有历史数据，知道哪些学生是挂科的（绿色：坏		学生），哪些是拿奖学金的（蓝色：好学生）。

​			LDA 会观察两类人的分布：

- **坏学生（绿）**：通常聚集在高熬夜、高游戏的区域。

- **好学生（蓝）**：通常聚集在低熬夜、低游戏的区域。

- **它寻找方向**：LDA 会画一条分界线（或投影轴），使得投影后，**蓝点和绿点分得越远越好**，且各自内部聚得越紧越好。

- **新指标**：LDA 可能会生成一个**“风险指数”**。

- **结果**：投影到这个轴上后，左边全是好学生，右边全是坏学生，中间有明确的间隙。

- **特点**：它**利用了标签信息**，牺牲了一部分总体方差，换取了类别的最大可分性。

**10、惩罚项**

​		岭回归的损失函数（Cost Function）：

​							$ J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2 + \lambda \sum_{j=1}^{n} \theta_j^2 $

​		**误差项：**  $ \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2$

​		**惩罚项：**  $\lambda \sum_{j=1}^{n} \theta_j^2$ ，L2 正则化项（惩罚项），所有特征的权重参数（θ1,θ2...）的平方和，λ（Lambda）是正则化系数（也叫超参数），它决定了惩罚的力度。

| 组成部分     | 目标                       | 如果只有它           |
| ------------ | -------------------------- | -------------------- |
| 训练误差     | 尽量拟合数据               | 模型疯狂扭曲，过拟合 |
| 惩罚项       | 尽量让权重小、曲线平滑     | 模型太平滑，欠拟合   |
| **两者结合** | **在拟合和平滑之间找平衡** | **刚刚好**           |

**11、“惩罚项”到底在惩罚什么？**

​		惩罚的是：模型参数的“大小”。

- **机制**：在模型训练（优化）过程中，算法不仅要最小化误差，还要最小化权重的平方和。
- **如果权重 θ 很大**：那么$ \sum_{} \theta_j^2$ 就会很大，导致总损失函数 J(θ) 变大。优化算法为了降低总损失，就会被迫把那些过大的 θ 往小的方向调整。
- **结果**：这就限制了模型的复杂度。权重越小，模型曲线就越平滑（如红线所示），从而对数据中的随机噪声不敏感，有效缓解了过拟合。

**12、参数 λ 的调节作用**

​		λ 是一个超参数，我们需要手动设置它的值，它的变化会直接影响模型：

- **当 λ=0 时**：惩罚项消失，岭回归退化为普通线性回归（绿线），容易过拟合。
- **当 λ 很大时**：惩罚力度极强，模型为了防止惩罚，会把所有 θ 都压缩成接近 0。此时模型会变得极度简单（甚至可能变成一条直线），导致**欠拟合**（高偏差）。
- **当 λ 适中时**：既能保持对数据的拟合能力，又能让参数不至于过大，达到最佳的泛化效果（红线）。

## **六、正则化与归一化**

![image-20260726181220432](https://gitee.com/MaGL/typorapic/raw/master/20260726181220558.png)

​		红色圆/圆柱代表 **L2 正则带来的参数限制区域**；蓝色碗/椭圆等高线代表 **SSE 误差面/误差等高线**。

​		**OLS 直接走到碗底（蓝点），而 Ridge 回归因为受到圆形约束的限制，只能在约束边界上找到 SSE 最小的切点（红点）。这个切点牺牲了一点拟合精度（SSE 稍大），但换来了参数的缩小和模型泛化能力的提升。**

**1、正则项 / 正则化**

​		正则项 / 正则化（Regularization）在线性回归里的作用， Ridge 回归（L2 正则）为什么会让回归系数比普通最小二乘 OLS 更小、更靠近原点。

​		普通最小二乘 OLS 只关心把 SSE 降到最低；Ridge 正则化还会额外要求参数 β1，β2 不能太大。

​		最终 Ridge 的解会被“拉回”靠近原点的位置，而不是完全跑到 OLS 最小点。

- 图 (a)   表达的意思是：**参数不能无限变大**。

​				纵轴是**SSE / ESS**：误差平方和：本质都是“预测误差平方加总”

​											$ SSE = \sum_{i=1}^n (y_i - \hat{y}_i)^2 $    (**真实值**-**预测值**)

​											$ SSE = (y - X\beta)^T (y - X\beta) $

​				横轴是参数 $β_1$，另一个水平方向是 $β_2$。

​				蓝色“碗”形曲面表示：不同 $(β_1,β_2)$ 对应不同的 SSE 值，碗底就是 SSE 最		小的位置。

​				**OLS / Least Square Coefficients**：普通最小二乘解，$\arg \min_{\beta} $ 表示使得		目标函数取最小值时的 β 取值

​											$ \hat{\beta} = \arg \min_{\beta} SSE(\beta) $

​											$ \hat{\beta} = (X^T X)^{-1} X^T y $

​				也就是说，如果不加任何限制，OLS 会直接走到蓝色碗的最低点。

​				红色圆柱表示正则项对参数的限制范围。可以粗略理解为：$ \beta_1^2 + \beta_2^2 \leq C $

- 图 (b) 

  **蓝色椭圆**是 SSE 的等高线。越靠近中心 β^，SSE 越小。

  **红色圆**是 Ridge/L2 正则的约束区域：$ \beta_1^2 + \beta_2^2 \leq C $，也就是参数必须待在这个圆里面或者边界上。

  **Ridge 回归系数：**红色箭头指的圆周上的点，表示 Ridge 回归最终选的参数。

  它一般不在 OLS 中心点，而是在**圆边界和 SSE 等高线接触/相切的地方**。

  因为圆把参数“限制住”了，所以不能自由到达 OLS 的最小点。

**2、OLS 和 Ridge 的区别**

|              | OLS                                  | Ridge                                                     |
| ------------ | ------------------------------------ | --------------------------------------------------------- |
| **目标**     | $ \arg \min_\beta SSE(\beta) $       | $ \arg \min_\beta [SSE(\beta) + \lambda \sum \beta_j^2] $ |
| **约束**     | 无约束，自由搜索整个参数空间         | 受圆形约束 $ \beta_1^2 + \beta_2^2 \leq C $限制           |
| **解析解**   | $ \hat{\beta} = (X^T X)^{-1} X^T y $ | $\hat{\beta} = (X^T X + \lambda I)^{-1} X^T y$            |
| **几何位置** | 蓝色碗底（等高线中心）               | 等高线与约束圆的**切点**                                  |

​		**OLS** 只关心一件事：让 SSE 尽可能小。

​		**Ridge** 同时关心两件事：让 SSE 小，**并且**让参数 β 本身不要太大。

**3、为什么要限制参数大小？**

​		防过拟合

​		举个例子：预测房价：price = β₁ · 面积 + β₂ · 年龄

| β₁ 正常      | β₁ 特别大       |                |
| ------------ | --------------- | -------------- |
| 面积 100→101 | 房价涨 0.3 万 ✅ | 房价涨 50 万 ❌ |

​		**β 越大，模型对那个特征越敏感，任何微小的波动都会被放大。**

**4、正则化到底在干什么**

​		**正则化就是告诉模型：别太较真，学个大概规律就行了，别把每一个细节都记住。**

**5、正则项与惩罚项的区别**

​		**它们是同一个东西，只是从不同角度看，所以叫法不同。**

​		就是公式里的 \($\lambda \sum \beta_j^2$) 这一部分：优化目标 = $\sum (y_i - \hat{y}_i)^2 + \lambda \sum \beta_j^2$ ，（优化目标 =误差项+惩罚项（正则项））

| 角度     | 叫法       | 关注什么                               |
| -------- | ---------- | -------------------------------------- |
| 数学角度 | **正则项** | 它是一种"正则化"（规范化、约束化）方法 |
| 效果角度 | **惩罚项** | 它的效果是"惩罚"大参数                 |

| 场景       | 用哪个词更自然 | 例子                           |
| ---------- | -------------- | ------------------------------ |
| 讲数学原理 | 正则项         | "这个公式加了一个正则项"       |
| 讲实际效果 | 惩罚项         | "加了一个惩罚项，防止参数太大" |
| 讲方法分类 | 正则化         | "L1 正则化、L2 正则化"         |
| 讲模型行为 | 惩罚           | "惩罚参数大的模型"             |

**6、L1 正则化和L2 正则化** 

|              | L1（Lasso）                                                  | L2（Ridge）                                           |
| ------------ | ------------------------------------------------------------ | ----------------------------------------------------- |
| **优化目标** | $ \min \sum (y_i - \hat{y}_i)^2 + \lambda \sum \|\beta_j\| $ | $ \min \sum (y_i - \hat{y}_i)^2 + \lambda \beta_j^2 $ |
| **惩罚的是** | 参数的**绝对值**之和                                         | 参数的**平方**之和                                    |

​		**L2 正则化（Ridge）：**

- **核心思想：**每个参数都给我变小一点，但不要砍掉任何一个。

- **惩罚方式：**$\lambda \sum\beta_j^2$

- **举例：**

  | 参数值 | 惩罚 β2*β*2 |
  | ------ | ----------- |
  | β = 1  | 1           |
  | β = 3  | 9           |
  | β = 10 | 100         |
  | β = -5 | 25          |

​				惩罚随参数**平方级增长**，参数越大罚得越重；无论正负，**平方都是正的**，		所以不区分方向；

​		**L1 正则化（Lasso）：**

- **核心思想：**不重要的特征，我直接把它砍掉。

- **惩罚方式：**$\lambda \sum \|\beta_j\|$

- **举例：**

  | 参数值 | 惩罚 $\|\beta\|$ |
  | ------ | ---------------- |
  | β = 1  | 1                |
  | β = 3  | 3                |
  | β = 10 | 10               |
  | β = -5 | 5                |

| 参数   | L2 惩罚 $\beta^2$ | L1 惩罚 $\|\beta\|$ |
| ------ | ----------------- | ------------------- |
| β = 1  | 1                 | 1                   |
| β = 3  | 9                 | 3                   |
| β = 10 | 100               | 10                  |

​			L2 对大参数惩罚极重（10 → 100），对小参数惩罚极轻（1 → 1）

​			L1 对所有参数**一视同仁**地惩罚（10 → 10，1 → 1）

| 维度           | L1（Lasso）                | L2（Ridge）             |
| -------------- | -------------------------- | ----------------------- |
| **惩罚项**     | $\lambda \sum \|\beta_j\|$ | $\lambda \sum\beta_j^2$ |
| **约束形状**   | 菱形（有尖角）             | 圆形（光滑）            |
| **参数变化**   | 部分参数变 0               | 所有参数缩小但不归零    |
| **特征选择**   | ✅ 自动选择                 | ❌ 不选择                |
| **稀疏性**     | 模型稀疏（很多 0）         | 模型稠密（没有 0）      |
| **共线性处理** | 随机选一个，砍掉其他       | 平摊贡献                |
| **适合场景**   | 特征多，少数有用           | 特征都有用，需控制大小  |

**7、标准化（Z-score 标准化）**

​		**它在干什么？**

​				**把数据"搬"到以 0 为中心，标准差为 1 的分布上。**

​									$ x_{stand} = \frac{x - \text{mean}(x)}{\sigma} =  \frac{x-\mu}{\sigma} $

​				**减去均值** → 让数据的中心移到 0，**除以标准差** → 让数据的"宽度"变成 1

​		**效果**：转换后的数据**均值变为 0，标准差变为 1**（如图左侧的正态分布曲线所示，中心从 μ 移到了 0，宽度标准化为 1）。

​		**特点**：处理结果**没有固定的边界**，可以有正数也可以有负数。由于使用了均值和标准差，它对极端异常值的敏感度相对较低（更加鲁棒）。

​		**用一个例子看懂：**

​				假设一个班 5 个学生的考试成绩：

| 学生 | 原始分数 |
| ---- | -------- |
| A    | 60       |
| B    | 70       |
| C    | 80       |
| D    | 90       |
| E    | 100      |

​					**第一步：算均值和标准差**：

​								$ \mu = \frac{60 + 70 + 80 + 90 + 100}{5} = 80 $

​								$ \sigma = 14.14 $

​					**第二步：每个数据减均值，除标准差**

| 学生 | 原始分 | 减均值    | 除标准差  | 标准化后  |
| ---- | ------ | --------- | --------- | --------- |
| A    | 60     | 60-80=-20 | -20÷14.14 | **-1.41** |
| B    | 70     | 70-80=-10 | -10÷14.14 | **-0.71** |
| C    | 80     | 80-80=0   | 0÷14.14   | **0**     |
| D    | 90     | 90-80=10  | 10÷14.14  | **0.71**  |
| E    | 100    | 100-80=20 | 20÷14.14  | **1.41**  |

**8、最值归一化**

​		**它在干什么？**

​				**把数据"压"到 0 到 1 之间。**

​									$ x_{norm} = \frac{x - \min(x)}{\max(x) - \min(x)} $

​				**减去最小值** → 让最小值变成 0，**除以（最大值 - 最小值）** → 让最大值变		成 1

​		**用一个例子看懂：**

​				假设 3 个学生的成绩：60、75、90，min=60,max=90,极差=90−60=30，		结果全部落在 **[0, 1]** 之间。

| 学生 | 原始分 | 减最小值 | 除极差 | 归一化后 |
| ---- | ------ | -------- | ------ | -------- |
| A    | 60     | 60-60=0  | 0÷30   | **0.00** |
| B    | 75     | 75-60=15 | 15÷30  | **0.50** |
| C    | 90     | 90-60=30 | 30÷30  | **1.00** |

**9、标准化与归一化对比**

|              | 标准化（Z-score）                                            | 归一化（Max-Min）                                            |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **结果范围** | 没有固定边界                                                 | [0, 1]                                                       |
| **对异常值** | **不太敏感**                                                 | **极度敏感**                                                 |
| **优点**     | 稳健，不怕极端值                                             | 直观，结果有明确边界                                         |
| **适合场景** | 数据中存在**异常值/离群点**（因为它对极值不敏感）、数据近似服从**正态分布（高斯分布）**、 | 需要数据严格限制在固定区间（如 **[0,1]**），无极端值、**图像处理**（像素值通常从 0-255 压缩到 0-1） |
|              | 后续使用的算法基于统计假设或距离度量，如 **SVM、逻辑回归、PCA（主成分分析）、线性回归**等 | 后续使用对输入范围敏感的算法，如 **KNN、K-Means 聚类、神经网络（尤其是带 Sigmoid/Tanh 激活函数时）**。 |

​		**归一化就是把数据线性压缩到 [0, 1]，非常直观；但一旦数据里有一个极端值，正常数据就会被挤成一团，失去区分度。**

​		**标准化就是把数据搬到以 0 为中心、标准差为 1 的分布上；没有固定边界，但对异常值更稳健。**

​		**经验法则**：如果你不确定用哪个，**优先尝试标准化 (Z-score)**，它在大多数场景下都是一个安全且通用的选择。

![image-20260726181257972](https://gitee.com/MaGL/typorapic/raw/master/20260726181258117.png)

10、为什么能“优化”？

​		图非常直观地解释了**为什么在训练模型（特别是使用梯度下降法时）需要做归一化/标准化**。

- **未归一化前 (Unnormalized: 狭长的椭圆)：**假设我们在做一个预测任务（比如预测房价）

​				有两个特征：x1 = 房屋面积（取值范围 0~2000 平方英尺）、x2 = 卧室数				量（取值范围 0~5）。

​				因为两个特征的**量纲和数值范围差异巨大**，在优化参数 w（权重）和 b				（偏置）时，损失函数（Cost Function）的等高线会呈现出**扁平、狭长				的椭圆形**。

​				**优化痛点**：在使用梯度下降寻找最低点（最优解）时，由于不同方向上的				梯度变化极不均匀（一个方向很陡，一个方向很平），更新路径会像左图				那样走出**“之”字形（锯齿状震荡）**。这不仅会导致收敛速度极慢，还可能				需要不断调整极小的基础学习率来防止越过最优解。

- **归一化后 (Normalized: 接近正圆)**

  经过特征缩放，所有特征都被拉到了相似的数值尺度（比如都在 0~1 或 -3~3 之间）。

  **优化优势**：此时损失函数的等高线变成了**接近圆形的同心圆**。梯度在各个方向上的变化趋于一致，梯度下降的箭头可以**几乎沿直线、直接地指向圆心（最优解）**。这大大加快了模型的收敛速度，提高了训练的稳定性。

## **七、逻辑回归、Softmax回归、损失函数**

![image-20260726181318573](https://gitee.com/MaGL/typorapic/raw/master/20260726181318690.png)

**1、线性回归 Linear Regression**

​		线性回归的形式通常或者多维特征时：

​							$ y = wx + b $

​							$ y = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b $

​		**线性回归的特点：**

- **输出范围无限制：**理论上线性模型的输出可以是 −∞ 到 +∞。
- **适合连续数值预测：**比如预测销售额、价格、长度、重量、分数等。
- **用直线/超平面拟合数据：**在一维特征时是一条直线；在多特征时是超平面。
- **常用损失函数：**均方误差 $ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $

**2、逻辑回归 Logistic Regression**

​		逻辑回归输出的是一个**概率值**，表示样本属于某一类的可能性。例如：

$ P(y = 1 | x) = 0.93 $，表示模型认为这个南瓜有 93% 的概率是“orange”类别。

​		逻辑回归不是回归吗？为什么用来分类？逻辑回归名字里有“回归”，但它其实是**分类算法**。内部先做了一个线性计算：$ z = wx + b $，这一步和线性回归很像，输出可以是任意实数。

但逻辑回归会再套一个 **Sigmoid 函数**，把任意实数压缩到 0,1 之间：$ \sigma(z) = \frac{1}{1 + e^{-z}} $

最终：$ P(y = 1 | x) = \sigma(wx + b) $，逻辑回归的完整形式是：$ \hat{y} = \frac{1}{1 + e^{-(wx+b)}} $

​		**Sigmoid 函数的作用：**Sigmoid 曲线就是右图里的“S 形曲线”。它的特点是：当 z 很大时，输出接近 1；当 z 很小时，输出接近 0；中间区域变化较快；输出可以被解释为概率；

![image-20260726181331006](https://gitee.com/MaGL/typorapic/raw/master/20260726181331110.png)

**3、线性 vs 逻辑回归的核心区别**

| **对比项**     | **线性回归**         | **逻辑回归**                     |
| :------------- | :------------------- | :------------------------------- |
| 问题类型       | 回归问题             | 分类问题                         |
| 输出           | 连续数值             | 类别概率 / 类别标签              |
| 输出范围       | 无限制               | 0 到 1 之间                      |
| 是否适合二分类 | 不适合直接做         | 非常适合                         |
| 核心函数       | 线性函数             | 线性函数 + Sigmoid               |
| 常用损失       | MSE、MAE 等          | 对数损失 / 交叉熵损失            |
| 例子           | 预测价格、销量、温度 | 判断垃圾邮件、是否患病、是否点击 |

**4、为什么不能直接用线性回归做分类？**

​		假设我们用线性回归输出一个值，然后规定：输出 > 0.5 算类别 1，输出 < 0.5 算类别 0，看起来好像也能分，但有问题。

​		问题一：输出可能超出 [0,1]

​				分类概率应该在 0 到 1 之间，但线性回归可能输出 -3、10、100。这些值		没法自然解释成概率。

​		问题二：异常值会严重拉偏直线

​				如果有一个极端样本，线性回归为了拟合它，可能把分界线整体拉开，导		致分类效果变差。

​		问题三：类别标签本身不是连续含义

​				比如：0 表示“不是橙色”，1 表示“橙色”。这里的 0 和 1 不是大小关系，		而是类别编号。强行用直线拟合可能不合理。

​				所以分类问题通常用逻辑回归、决策树、SVM、神经网络等方法。

**5、逻辑回归的损失函数：为什么不用 MSE？**

​		逻辑回归如果也用均方误差，会出现非凸优化问题，梯度下降可能陷入局部最优，训练不稳定。

​		逻辑回归通常使用 **二元交叉熵损失 Binary Cross-Entropy Loss**，也叫对数损失 Log Loss

![image-20260726181352635](https://gitee.com/MaGL/typorapic/raw/master/20260726181352769.png)

**6、逻辑回归不是在算“误差平方”**

​		线性回归常用均方误差：$ J = \frac{1}{m} \sum (\hat{y} - y)^2 $

​		但逻辑回归如果用均方误差，损失函数会非凸，优化时容易卡在局部最优。

​		所以逻辑回归通常用 **对数损失 / 交叉熵损失 / log loss**：

​							$ J(w, b) = -\frac{1}{m} \sum_{i=1}^m \left[ y^{(i)} \log(\hat{y}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{y}^{(i)}) \right] $

​			其中：$ \hat{y}^{(i)} = \sigma(z^{(i)}) = P(y = 1 | x^{(i)}) $，也就是模型预测“类别为 1”的概率。

**7、分情况看损失函数**

​		因为二分类标签 y 只能是 0 或 1，所以可以写成两个式子。

​		**当真实标签 y=1**，$ Cost = -\log(\hat{y}) $，意思是：如果模型预测 $\hat{y}$ 接近 1，损失接近 0，如果模型预测 $\hat{y}$ 接近 0，损失会非常大，比如医生说“你没病”，但实际有病，模型就要受到很大惩罚。

​		**当真实标签 y=0**，$ Cost = -\log(1 - \hat{y}) $，意思是：如果 $\hat{y}$ 接近 0，损失小，如果 $\hat{y}$ 接近 1，损失大，比如模型把正常邮件判成垃圾邮件，也要受惩罚。

**8、为什么用 log？**

​		核心原因是：**逻辑回归输出是概率，用对数损失可以惩罚“错误预测的高置信度”。**对数损失会对“ confidently wrong ”给很重惩罚。

| **真实 y** | **预测 y^** | **含义**         | **损失大概** |
| :--------- | ----------: | :--------------- | -----------: |
| 1          |         0.9 | 预测对，且很自信 |           小 |
| 1          |        0.51 | 预测对，但不自信 |         中等 |
| 1          |         0.1 | 预测错，且很自信 |         很大 |
| 0          |         0.1 | 预测对，且很自信 |           小 |
| 0          |        0.49 | 预测对，但不自信 |         中等 |
| 0          |         0.9 | 预测错，且很自信 |         很大 |

**9、Sigmoid 导数很重要**

​		Sigmoid：$ \sigma(z) = \frac{1}{1 + e^{-z}} $，它有漂亮性质：$ \sigma'(z) = \sigma(z)(1 - \sigma(z)) $

​		这个性质让逻辑回归梯度计算很方便。直观理解：当 σ(z) 接近 0 或 1 时，导数接近 0，当 σ(z)=0.5 附近时，导数较大。

| $\sigma(z)$ | $1 - \sigma(z)$ | 导数 = $\sigma(z)(1 - \sigma(z))$ |
| ----------- | --------------- | --------------------------------- |
| 0.01        | 0.99            | **0.0099** ≈ 0                    |
| 0.10        | 0.90            | **0.09**                          |
| 0.30        | 0.70            | **0.21**                          |
| **0.50**    | **0.50**        | **0.25** ← 最大                   |
| 0.70        | 0.30            | **0.21**                          |
| 0.90        | 0.10            | **0.09**                          |
| 0.99        | 0.01            | **0.0099** ≈ 0                    |

​		也就是说，模型在“很确定”的时候梯度小，在“不太确定”的区域梯度更活跃

​		也要注意：如果 z 绝对值很大，Sigmoid 会饱和，梯度接近 0，可能导致梯度消失。这也是为什么深层神经网络里不一定总用 Sigmoid。

![image-20260726181418681](https://gitee.com/MaGL/typorapic/raw/master/20260726181418826.png)

**10、二分类 Binary Classification、多分类 Multiclass Classification**

​		**二分类 Binary Classification**		

​				逻辑回归默认学的是**线性决策边界**：$ w^T x + b = 0 $，对应：$\hat{y}=0.5$

​				在这条线一侧预测为 0，另一侧预测为 1。如果数据像图中这样大致能被		直线分开，逻辑回归就很合适。但如果类别是环形、螺旋形、交错复杂分布，		单靠原始特征的逻辑回归就不够，需要做特征变换或用更复杂模型。

​		**多分类 Multiclass Classification**

​				逻辑回归也可以做多分类。常见方式有两种：One-vs-Rest / OvR，对每个		类别训练一个二分类器：Class 1 vs 其他、Class 2 vs 其他等，预测时看哪个分		类器分数/概率最高。

​				多分类版本直接用 Softmax：$ P(y = k|x) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}} $，所有类别概率加起		来等于 1。

![image-20260726181444465](https://gitee.com/MaGL/typorapic/raw/master/20260726181444588.png)

Sigmoid / 逻辑回归常用于二分类；Softmax 回归是它的多分类版本，把多个类别的得分转换成一组概率。

**11、Sigmoid 和 Softmax 的公式对比**

​		Sigmoid：$ \sigma(z) = \frac{1}{1 + e^{-z}} $

​		Softmax：$ S(z)_i = \frac{e^{z_i}}{\sum_{k=1}^C e^{z_k}} $，$z_i$是第 i 个类别的得分；C 是类别总数；分母是所有类别指数得分之和

​		Softmax 把一组分数 z1,z2,...,zC 变成一组概率：$ S(z)_1, S(z)_2, ..., S(z)_C $，并且满足：$ 0 < S(z)_i < 1 $，$ \sum_{i=1}^C S(z)_i = 1 $，也就是说，所有类别概率加起来等于 1。

| **项目** | **逻辑回归 / Sigmoid** | **Softmax 回归** |
| :------- | :--------------------- | :--------------- |
| 任务     | 二分类                 | 多分类           |
| 输出     | 一个 0~1 概率          | 多个类别概率     |
| 函数     | Sigmoid                | Softmax          |
| 概率和   | 单个概率表示正类可能   | 所有类概率和为 1 |
| 损失     | 二分类交叉熵           | 多分类交叉熵     |
| 边界     | 线性边界               | 线性边界         |

**12、Softmax 回归的结构**

​		右边图里有多个输出节点。每个类别都有自己的：**权重、线性加权、偏置 b、净输入 Σ**

​		比如有 3 个类别时，模型会算出：$ z_1=w_1^T x + b_1 $、$ z_2 = w_2^T x + b_2 $、$ z_3=w_3^T x + b_3 $，

​		然后放进 Softmax：$ P(y = 1|x) = \frac{e^{z_1}}{e^{z_1} + e^{z_2} + e^{z_3}} $、$ P(y = 2|x) = \frac{e^{z_2}}{e^{z_1} + e^{z_2} + e^{z_3}} $、$ P(y = 3|x) = \frac{e^{z_3}}{e^{z_1} + e^{z_2} + e^{z_3}} $

​		最后选择概率最大的类别：$ \hat{y} = \arg \max_i P(y = i|x) $



![image-20260726181502966](https://gitee.com/MaGL/typorapic/raw/master/20260726181503092.png)

**13、回归损失函数（Regression Loss Functions）**

​		回归任务预测的是连续值（比如房价、温度、销售额）。以下是几种常见的回归损失：

- **均方误差（MSE / L2 Loss）**

  ​					$ \mathcal{L}_{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - f(x_i))^2 $

  ​		这是最经典的回归损失，计算预测值与真实值之差的**平方**的平均值。

  ​		**特点**：因为平方了，所以对“大误差”惩罚非常重。如果数据里有异常值（比如本来房价100万，模型预测成1000万），MSE 会变得巨大。

- **平均绝对误差（MAE / L1 Loss）**

  ​						$ \mathcal{L}_{MAE} = \frac{1}{N} \sum_{i=1}^{N} |y_i - f(x_i)| $

  ​		计算预测值与真实值之差的**绝对值**的平均。

  ​		**特点**：对异常值的鲁棒性比 MSE 好。不管误差是 10 还是 1000，它都是线性增长，不会像平方那样爆炸。

- **均方根误差（RMSE）**

  ​						$ \mathcal{L}_{RMSE} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} (y_i - f(x_i))^2} $

  ​		就是 MSE 开根号。

  ​		**特点**：**量纲**和原始目标变量 y 保持一致。比如预测房价（单位是“万元”），MSE 的单位就是“万元的平方”，而 RMSE 还是“万元”，更直观。

- **Huber Loss**

  ​						$ L_{\text{Huber}} = 
  \begin{cases} 
  \frac{1}{2}(y_i - f(x_i))^2, & |y_i - f(x_i)| \leq \delta \\ 
  \delta(|y_i - f(x_i)| - \frac{1}{2}\delta), & \text{otherwise} 
  \end{cases} $

  ​			结合了 MSE 和 MAE 的优点：

  ​					当误差 **小于阈值 δ** 时，行为像 MSE（平方项，处处可导，梯			度平滑）；

  ​					当误差 **大于阈值 δ** 时，行为像 MAE（线性增长，不会被异常			值带飞）

  ​			**核心思想**：小误差时精细优化，大误差时稳健处理。δ 是一个需要调节的超参数，控制"多大算大误差"。

- **Log Cosh Loss** 

  ​						$ L_{\text{LogCosh}} = \frac{1}{N} \sum_{i=1}^N \log(\cosh(f(x_i) - y_i)) $

  ​			可以理解为 Huber Loss 的 **平滑近似版本**：

  ​					对于小误差，近似于 $  \frac{1}{2} (y_i - f(x_i))^2 ) $（行为像MSE）

  ​					对于大误差，近似于 $ |y_i - f(x_i)| - \log 2$（行为像 MAE）

  ​			**特点**：二阶处处可导（Huber 在 δ 处导数有折点），在优化过程中梯度更加平滑，不需要手动选阈值 δ。

| 误差大小     | MSE (L2)     | MAE (L1)   | RMSE         | Huber      | Log Cosh   |
| ------------ | ------------ | ---------- | ------------ | ---------- | ---------- |
| 小误差       | 平方增长     | 线性增长   | 介于两者之间 | 像 MSE     | 像 MSE     |
| 大误差       | **爆炸增长** | 线性增长   | 介于两者之间 | **像 MAE** | **像 MAE** |
| 异常值敏感度 | **很敏感**   | 鲁棒       | 较敏感       | 可调       | 自适应     |
| 可导性       | 处处可导     | 零点不可导 | 处处可导     | 处处可导   | 处处可导   |

![image-20260726181516704](https://gitee.com/MaGL/typorapic/raw/master/20260726181516825.png)

**14、分类损失函数（Classification Loss Functions）**

- **二元交叉熵（BCE / Binary Cross Entropy）**

  ​						$ \mathcal{L}_{BCE} = \sum_{i=1}^N y_i \cdot \log(p(x_i)) + (1 - y_i) \cdot \log(1 - p(x_i)) $

  ​			这就是**逻辑回归**使用的损失函数（对数损失）。p(xi) 就是 Sigmoid 输出的概率 $\hat{y}$

  ​			**特点**：当真实标签 y=1 但模型预测概率接近 0 时，log(0) 趋向负无穷，前面有负号，所以损失会**极大**。这强力惩罚“自信地预测错”。		

- **Hinge Loss**

  ​						$ \mathcal{L}_{Hinge} = \max(0, 1 - (f(x) \cdot y)) $

  ​			主要用于 **SVM（支持向量机）**。

  ​			**特点**：它不仅要求分对，还要求“足够自信”（有一个间隔 margin）。如果分对了但置信度不高，依然会有损失。这让 SVM 更关注那些“难分”的样本（靠近决策边界的点）。

- **交叉熵损失（Cross Entropy Loss）**

  ​						$ L_{CE} = -\frac{1}{N} \sum_{i=1}^{N} \sum_{j=1}^{M} y_{ij} \log(f(x_{ij})) $

- **KL 散度（KL Divergence）**

  ​						$ L_{KL} = \sum_{i=1}^{N} y_i \log \left( \frac{y_i}{f(x_i)} \right) $



## **八、理解神经网络反向传播**

![image-20260726181540749](https://gitee.com/MaGL/typorapic/raw/master/20260726181540919.png)

从逻辑回归（LR）到神经网络（NN）的演进脉络。

**1、Binary LR（二分类逻辑回归）**

​		**结构解析：**输入 x → 加权求和 Σ → 激活函数σ（Sigmoid）→ 输出概率（0~1）

​		**核心公式：**		$ z = w^T x + b, \quad \hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}} $

​		**本质：**单个神经元 = 线性变换 + 非线性激活；只能解决**线性可分**问题（如：根据肿瘤大小判断良恶性）

​		延伸问题：为什么必须加Sigmoid？直接输出z不行吗？

​				z的范围是(-∞, +∞)，而分类需要概率[0,1]。Sigmoid把任意实数"压缩"成		概率解释。但注意：现代神经网络中间层很少用Sigmoid（易梯度消失），多		用ReLU。

**2、Multiclass LR（多分类逻辑回归 / Softmax回归）**

​		**结构解析：**输入 x → 多个并行Σ（每个类别一个分数）→ Softmax → 多输出概率（和为1）

​		**Softmax公式：**		$ \text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}} $

​		延伸问题：Softmax和Sigmoid什么关系？多个Sigmoid能代替Softmax吗？

​				Sigmoid是Softmax的K=2特例。但**多标签分类**（一张图同有"猫"和"狗"）		用多个独立Sigmoid；**多类别互斥**（只能是"猫"或"狗"之一）必须用Softmax保		证概率和为1。

**3、神经网络的直观例子（房价预测）右上角**

​		图示要点：**输入**：房屋特征（面积、卧室数、邮编、年代等）→ 一行数据；**隐藏层**：多层非线性变换，"自动提取"特征组合；**输出**：连续值（价格）→ 这是**回归**问题；

​		延伸问题：为什么叫"隐藏"层？

​				隐藏层的神经元权重通过**数据训练自动学习**。比如第一层可能学"位置好		不好"，第二层组合成"豪华程度"等人类未必显式定义的特征。这就是**表征学		习（Representation Learning）**。

**5、理解图 从左到右**

​		**① Input layer 输入层**

​			输入特征：$x_1,x_2,…,x_i,…,x_m$ ，可以理解为一条样本有 m 个特征。

​			例如预测房价时：x=[面积,房间数,楼层,地段评分,房龄]，那么 m=5。

​			输入层本身通常不“计算”什么，它主要负责把原始特征传给下一层。

​		**② Hidden layer 隐藏层**

​			中间橙色的是隐藏层：$Hidden layer 1, Hidden layer 2, …, Hidden layer s$ 		每一层都有若干个神经元/节点。

​			隐藏层的作用是：把输入特征进行逐层变换，自动抽取更高级、更复杂的表		示。

​			比如图像任务中：第一层可能学边缘、颜色变化；第二层可能学角点、纹		理；更深层可能学眼睛、轮子、人脸、物体部件等。

​		**③ Output layer 输出层**

​			右边青色的是输出层：$y_1,y_2,…,y_j,…,y_n$，输出层给出模型预测结果。

​			不同任务输出形式不同：

| **任务** | **输出层形式**                                |
| :------- | :-------------------------------------------- |
| 二分类   | 1个输出，接 Sigmoid                           |
| 多分类   | n个类别输出，接 Softmax                       |
| 回归     | 1个或多个连续值输出，通常不加激活或接线性输出 |

​				例如手写数字识别 MNIST：输出=[P(0),P(1),P(2),…,P(9)]，共 10 个输			出。

**6、正向传播 Forward propagation**

​		图中下方红色箭头表示正向传播，方向是从左到右：

​									输入→隐藏层1→隐藏层2→⋯→输出层

​		每一层的计算大致是：$ z = Wx + b $

​		然后经过激活函数：$ a = \sigma(z) $

​		例如某一层：$ h^{(1)} = \sigma(W^{(1)}x + b^{(1)}) $

​		下一层：$ h^{(2)} = \sigma(W^{(2)}h^{(1)} + b^{(2)}) $

​		最后输出：$ \hat{y} = f(x; W, b) $，这里$\hat{y}$是模型预测值。

| 序号 | 公式                                           | 含义         | 层级         |
| :--- | :--------------------------------------------- | :----------- | :----------- |
| ①    | $ z = Wx + b $                                 | 线性变换     | 单神经元输入 |
| ②    | $ a = \sigma(z) $                              | 激活输出     | 单神经元输出 |
| ③    | $ h^{(1)} = \sigma(W^{(1)}x + b^{(1)}) $       | 第一隐藏层   | 隐藏层1      |
| ④    | $ h^{(2)} = \sigma(W^{(2)}h^{(1)} + b^{(2)}) $ | 第二隐藏层   | 隐藏层2      |
| ⑤    | $ \hat{y} = f(x; W, b) $                       | 整体网络函数 | 端到端映射   |

**7、 误差 Error / Loss**

​		图右侧有：$y_j$和Actual value，也就是：$y_j$模型预测值 $\hat{y}$，Actual value：真实标签 y，两者比较得到误差。

​		常见损失函数：

​				回归问题用 MSE： 	$ L = \frac{1}{2}(\hat{y} - y)^2 $ 	或者  	$ L = \frac{1}{n} \sum_{i=1}^n (\hat{y}_i - y_i)^2 $

​				分类问题常用交叉熵：

​						二分类：	$ L = -[y \log \hat{y} + (1 - y) \log(1 - \hat{y})] $ 

​						多分类：	$ L = -\sum_{k=1}^C y_k \log \hat{y}_k $

​		

**8、反向传播 Back propagation**

​		图中上方虚线箭头从右到左，表示反向传播。

​		它的作用是：根据输出误差，计算每一层参数对误差的梯度，然后更新权重。

​		简单说：

​				先正向算预测值；

​				比较预测值和真实值，得到损失；

​				从输出层往回算梯度；

​				用梯度下降更新 W 和 b。

​		参数更新：		$ W \leftarrow W - \eta \frac{\partial L}{\partial W} $		$ b \leftarrow b - \eta \frac{\partial L}{\partial b} $	其中 η 是学习率。

**9、为什么需要反向传播？**

​		如果没有反向传播，我们不知道：哪个权重该调大？哪个权重该调小？第一层隐藏层的参数对最终错误负多少责任？

​		反向传播通过链式法则，把输出层的误差“分配”回前面每一层。

​		例如：	$ \frac{\partial L}{\partial W^{(1)}} $ ，表示第一层权重对总损失的影响。

​		虽然第一层离输出很远，但通过链式求导仍然可以计算它的梯度。

## 九、梯度消失问题

![image-20260726181619840](https://gitee.com/MaGL/typorapic/raw/master/20260726181619983.png)

**1、什么是梯度消失？**

​		核心原因：反向传播是“连乘”

​		一个重要公式：$ \frac{\partial E}{\partial w_x} = \frac{\partial E}{\partial O_{out}} * \frac{\partial O_{out}}{\partial O_{in}} * \frac{\partial O_{in}}{\partial h_4} * \frac{\partial h_4}{\partial h_7} * \frac{\partial h_7}{\partial w_x} $

​		意思是：要更新靠近输入层的权重，梯度必须从输出层一路乘回输入层。

​		如果每层传回来的导数都小于 1，比如大约是 0.2、0.3、0.5，那么多层连乘后：0.3×0.3×0.3×⋯ 	会越来越小。

​		假设每层平均乘 0.25，经过 10 层：$0.25^{10}≈0.00000095$，几乎接近 0。

​		于是靠近输入层的参数梯度极小，参数几乎不更新，模型就像“前面几层不学习，只有后面几层在动”。这就是**梯度消失**。

**2、什么是梯度爆炸？**

​		如果反向传播过程中，每层梯度因子大于 1，或者权重初始化太大，那么连乘后会迅速变大：2×2×2×⋯	，很快变成非常大。

​		结果：参数更新步长巨大、loss 突然 NaN、权重变成 inf、模型训练崩溃



![image-20260726181634708](https://gitee.com/MaGL/typorapic/raw/master/20260726181634858.png)

**3、梯度太小与梯度太大**

​		**梯度太小：**

​				靠近输入层的权重几乎得不到有效更新。

​				**表现**：loss 下降很慢、前面层参数几乎不变、深层网络像浅层网络一样工		作、训练很久也没效果

​		**梯度太大：**

​				权重更新步长太大。

​				**表现：**loss 忽大忽小、参数飞掉、出现 NaN、模型不收敛

​		**常见缓解方法：**

​				使用 ReLU 类激活函数、Batch Normalization、合适的权重初始化、残差		连接 ResNet、梯度裁剪 Gradient Clipping、Layer Normalization，常用于		Transformer/RNN 类结构。	

**4、残差连接为什么能缓解梯度消失？**

​		

​		反向传播时，梯度可以沿着“短路路径”直接传回去。

​		直观说，残差连接给梯度修了一条高速公路，不让它只靠一层层连乘回来。这也是 ResNet 能训练非常深网络的关键原因之一。

​		**（1）从反向传播的数学角度**

​					普通深层网络：$ x \to F(x) $，残差网络：$ y = F(x) + x $

​					假设一个信号要经过 L*L* 层传递，每一层的梯度传递涉及乘以该层的权			重矩阵（或导数）：$ \frac{\partial \mathcal{L}}{\partial x} = \frac{\partial \mathcal{L}}{\partial y} \cdot \frac{\partial y}{\partial x} = \frac{\partial \mathcal{L}}{\partial y} \cdot \frac{1}{\partial F_{L-1}} \cdot \frac{\partial F_{L-1}}{\partial F_{L-2}} \cdots \frac{\partial F_1}{\partial x} $

​					这是 **L个矩阵的连乘**。如果每层的梯度（雅可比矩阵的谱范数）小			于 1，连乘后就会指数级衰减 → **梯度消失**。

​					反向传播时：$ \frac{\partial y}{\partial x} = \frac{\partial F(x)}{\partial x} + \frac{\partial x}{\partial x} = \frac{\partial F(x)}{\partial x} + \mathbf{I} $，多了一个 单位矩阵 I			（恒等映射的导数）。

​					推广到 L 层残差块（从输入 x 经过 L 个残差块得到输出 $y_L$）：

​					$ y_L = x + \sum_{i=1}^L F_i(x_i) $ ，

​					对输入 x*x* 求梯度：$ \frac{\partial \mathcal{L}}{\partial x} = \frac{\partial \mathcal{L}}{\partial y_L} \cdot \left( \mathbf{I} + \frac{\partial}{\partial x} \sum_{i=1}^{L} F_i(x_i) \right) $

​					关键点：不管网络多深，I 始终存在，梯度至少有 1 这么大的分量可			以传播回去，不会消失。

​		**（2）用一个具体例子感受差距**

​					假设每层的梯度因子是 0.9：

| 网络深度 L | 普通网络梯度因子 $(0.9)^L$ | 残差网络（最坏情况近似） |
| :--------: | :------------------------: | :----------------------: |
|     10     |            0.35            |     ≥ 1（因为有 I）      |
|     50     |           0.005            |           ≥ 1            |
|    100     |        $2.6×10^−5$         |           ≥ 1            |

​					普通网络的梯度指数级衰减，残差网络保证了梯度的"底线"。

​		**（3）为什么叫"高速公路"？**

​					可以这样理解信息流的两条路径：

```
输入 x ──────────────────────────→ (+) ──→ 输出 y
   │                               ↑
   └──→ [卷积/BN/ReLU] → F(x) ──────┘
```

- **路径 1（跳跃连接）**：零成本直接传递，梯度畅通无阻
- **路径 2（残差分支）**：通过权重层学习修正量 F(x)*F*(*x*)

​		训练初期，F(x)的权重接近零，梯度几乎全部走路径 1，相当于浅层网络在训练。随着训练推进，F(x)逐渐学习到有用的残差。这给了网络一个**从浅到深的渐进式学习能力**。



**5、归一化为什么有帮助？**

​		（1）BatchNorm / LayerNorm 的作用是让每一层输入分布更稳定。

​					神经网络是一层叠一层的结构。训练时，前一层的权重在不断更新，这			意味着**后一层看到的输入数据的分布也在不断变化**。

​					归一化做的事就是——**在每一层之前，把"靶子"固定住**。不管上游怎么			变，归一化都会把数值重新拉回到均值为 0、方差为 1 的标准范围内。

​		（2）如果没有归一化，某些层输出可能太大或太小，经过激活函数后进入饱					和区，比如 Sigmoid 两端导数接近 0。

​		（3）归一化后：激活值更集中在导数较大的区域、梯度更稳定、训练更快、		

**6、权重初始化为什么重要？**

​		如果权重太大，正向传播信号可能放大，反向梯度也可能爆炸。

​		如果权重太小，信号逐层缩小，输出可能趋近 0，梯度也可能消失。

​		常用初始化：

​				Xavier / Glorot 初始化：适合 Sigmoid、Tanh

​				He 初始化：适合 ReLU 类激活函数

​		它们的目标都是尽量让每层的输出方差和梯度方差保持稳定。

**7、梯度消失是不是“损失变成 0”？**

​		不是。梯度消失是指**梯度接近 0**，不是损失接近 0。很多时候梯度消失了，loss 还很高，因为模型根本没继续学好。

**8、梯度消失和过拟合有什么区别？**

​		梯度消失：训练过程中前面层学不动，通常表现为训练集也学不好。

​		过拟合：训练集表现很好，测试集表现差。

​		当然实际中它们也可能同时出现。

**9、为什么深层网络更容易梯度消失？**

​		因为反向传播要经过更多层连乘。

​		层数越多，小数字连乘越容易趋近 0，大数字连乘越容易爆炸。

**10、ReLU 会不会梯度爆炸？**

​		ReLU 主要缓解梯度消失，但不保证避免梯度爆炸。

​		如果权重很大、学习率很高，或者网络结构特殊，比如 RNN，仍然可能爆炸。

​		所以常配合：合理初始化、归一化、梯度裁剪、合适学习率

**11、如果我把学习率调小，能解决梯度爆炸吗？**

​		可以缓解，但不一定根治。学习率小会让更新步长变小，但如果梯度本身已经极其巨大，还是可能不稳定。

​		更标准的方法是梯度裁剪：$ g \leftarrow g \cdot \frac{threshold}{\|g\|} $	当梯度超过阈值时进行缩放。

**12、RNN / LSTM 为什么特别怕梯度消失/爆炸？**

​		RNN 处理序列时会把同一个循环结构展开成很多步，相当于一个很深的网络。

​		反向传播要跨越很多时间步，梯度连乘严重。

​		LSTM 用门控机制和细胞状态来缓解，但也不是绝对解决。

**13、怎么判断自己的网络出现了梯度消失？**

​		可以观察：

​				前面层梯度范数远小于后面层
​				loss 长时间不下降
​				早期层权重几乎不变
​				加深网络后效果反而变差

![image-20260726181649404](https://gitee.com/MaGL/typorapic/raw/master/20260726181649487.png)

**14、为什么 Sigmoid / Tanh 容易导致梯度消失？**

​		图上画激活函数及其导数。

​		Sigmoid：$ g(z) = \frac{1}{1 + e^{-z}} $			导数：$ g'(z) = g(z)(1 - g(z)) $

​		最大值是 0.25，而且当 z 很大或很小时，导数接近 0。也就是说，Sigmoid 的输出被压到 0~1 之间，大部分区域的导数都很小。如果很多层都用 Sigmoid，反向传播时就会不断乘上很小的数，梯度容易消失。

​		Tanh：		$ \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} $		，输出范围是 −1 到 1。它的导数最大值是 1，比 Sigmoid 好一些，但当输入绝对值较大时，导数仍然会趋近 0。所以 Tanh 也比 Sigmoid 好，但深层网络中仍可能有梯度消失。

​		Linear 线性激活：导数恒为常数，比如图中红色线接近 1。但问题是：如果全部层都线性，那么多层网络等价于一层线性变换，无法表达复杂非线性关系。所以不能简单全用线性激活。

**ReLU 为什么常用？**

​		ReLU：$ ReLU(z) = \max(0, z) $

​		当 z>0 时，导数是 1。这避免了“梯度越乘越小”的问题，因为正区间梯度不会被压缩到很小。

​		但 ReLU 也有问题：如果某个神经元输入一直小于 0，那么它永远不激活，梯度一直为 0，称为 **Dead ReLU 问题**。

​		所以有改进版：Leaky ReLU、PReLU、ELU、GELU常用于 Transformer

## 十、激活函数、批量归一化、参数初始化

![image-20260726181703348](https://gitee.com/MaGL/typorapic/raw/master/20260726181703445.png)

**1、常见激活函数**

​		**ELU（Exponential Linear Unit）：**负区间平滑趋近于一个负值，不是		硬零。相比 ReLU 可缓解“神经元死亡”问题。

​		**GELU（Gaussian Error Linear Unit）**：平滑非线性激活，Transformer、BERT、GPT 等模型中常用。形状类似 ReLU，但负区间不会完全置零。

​		**Leaky ReLU：负区间有一个很小的正斜率。**解决普通 ReLU 在负输入时		梯度为 0 的问题。

​		**Parametric ReLU（PReLU）：**类似 Leaky ReLU，但负区间斜率可作为	可学习参数。比固定 Leaky ReLU 更灵活。

​		**ReLU（Rectified Linear Unit）：**最经典激活函数之一：`f(x) = max(0, x)`。计算简单、收敛快，但负区间梯度为 0，可能出现“死 ReLU”。

​		**SELU（Scaled ELU）：带缩放的 ELU，理论上可帮助自归一化神经网络保持稳定分布。**通常需要配合特定初始化和正则化使用。

​		**Sigmoid：**输出在 `(0, 1)` 之间。常用于二分类输出层，但隐藏层中容易梯度消失。

​		**Swish / SiL（Sigmoid-Weighted Linear Unit）：x * sigmoid(x) 形式。**平滑、非单调，在一些深层网络中表现优于 ReLU。

​		**Softmax：**将一组数值转换为概率分布，输出和为 1。多用于多分类问题的输出层。

​		**Softplus：**log(1 + exp(x))，可看作 ReLU 的光滑版本。始终为正，但计算量比 ReLU 大。

​		**Tanh：**输出在 `(-1, 1)` 之间，以 0 为中心。比 Sigmoid 更适合某些隐藏层，但两端仍可能饱和、梯度消失。

​		**Mish：**平滑、非单调激活函数，表现常优于 ReLU / Swish 的某些场景。计算稍复杂，但实践效果不错。

**简单选择建议：**

​		**隐藏层默认尝试**：ReLU、Leaky ReLU、GELU、Swish、Mish

​		**CNN / 传统网络**：ReLU 仍很常用

​		**Transformer / 大模型相关**：GELU、Swish 常见

​		**二分类输出层**：Sigmoid

​		**多分类输出层**：Softmax

​		**需要输出在 `-1~1` 或零中心化**：Tanh 可考虑

**2、批量归一化 / Batch Normalization（BN）**

​		**核心思想是：**在神经网络的某一层输出后，对一个 mini-batch 的数据按特征维度做归一化，把分布拉回到接近均值为 0、方差为 1 的标准分布，然后再用可学习参数做缩放和平移。

​		**BN 的基本公式：**

​				计算流程是：$ \hat{x} = \frac{x - \mu}{\sigma} $，$ y = \gamma \hat{x} + \beta $

​				x：某一层输出的特征值；μ：当前 mini-batch 中该特征的均值；

​				σ：当前 mini-batch 中该特征的标准差；

​				$\hat{x}$：归一化后的值；γ：可学习的缩放参数 scale；

​				β：可学习的偏移参数 shift / bias；y：最终 BN 输出；

**3、为什么要做 BN？**

​		训练深层网络时，每一层的输入分布会随着前面层参数更新而不断变化，这叫做 **内部协变量偏移（Internal Covariate Shift）**。

​		BN 的作用主要包括：

- **稳定训练过程**：让每层输入分布更稳定，减少层与层之间的耦合。
- **加速收敛：**可以使用更大的学习率，模型通常更快收敛。
- **缓解梯度消失 / 梯度爆炸：**尤其对 Sigmoid、Tanh 这类容易饱和的激活函数有帮助。
- **降低对初始化的敏感度：**网络没那么依赖精细的权重初始化。
- **有一定正则化效果：**因为每个 batch 的均值和方差有噪声，类似轻微正则化。但不能替代 Dropout、权重衰减等正则化方法。

**4、右上图中的流程怎么理解？**

​		**（1）输入一个 batch 的特征**

​					假设有 m 个样本，每个样本有若干特征。

​		**（2）计算均值和标准差**

​					对每个特征通道 / 特征维度，计算当前 batch 的：$ \mu_B, \sigma_B $

​		**（3）归一化**

​					把每个特征值减去均值，再除以标准差：$ \hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} $

​					实际实现里通常会加一个小常数 ϵ，防止除以 0。

​		**（4）缩放和平移**

​					用 γ 和 β 恢复表达能力：$ y = \gamma \hat{x} + \beta $

​					如果 γ=σ、β=μ，网络可以近似还原原始分布。

​		**（5）维护移动平均**

​					训练时会维护：$μ_{moving},σ_{moving}$

​					推理阶段通常使用这些移动平均统计量，而不是当前 batch 的统计量。

![image-20260726181739050](https://gitee.com/MaGL/typorapic/raw/master/20260726181739174.png)

**5、为什么不能全零初始化？**

​		**如果所有权重都初始化为 0：**每一层所有神经元输出相同；反向传播时梯度也相同；神经元无法“分化”，网络等价于只有一个神经元；

​		所以权重必须**随机初始化**，如图左上所示，给不同连接不同的小随机数（0.23, -0.14, 0.31...）。

**6、 随机初始化的分布**

​		图下方展示了两种常见随机分布：

​				**正态分布（Normal / Gaussian）：**均值 μ=0，大部分值集中在 0 附近，		两头少

​				**均匀分布（Uniform）：**均值 μ=0（或对称区间），在某个范围内等概率		取样

​		**关键**：不能太简单粗暴地取 `randn()` 或 `rand()`，否则可能：

​				权重太大 → 激活值饱和（Sigmoid/Tanh 两端平坦）→ 梯度消失

​				权重太小 → 信号逐层衰减 → 梯度消失 / 特征学不动

​		所以需要**有尺度的初始化方法**。

**7、两种经典初始化方法**

​		**（1）Xavier 初始化**：$ w \sim \mathcal{N}\left(0, \frac{2}{n_{in} + n_{out}}\right) $，适合 Sigmoid/Tanh

​				*$n_{in}$*：该层每个神经元接收的输入个数（上一层的神经元数）

​				*$n_{out}$*：**该层的神经元个数**（即输出个数）

​				**具体例子：**

```
上一层有 256 个神经元，当前层有 128 个神经元

n_in  = 256
n_out = 128

方差 = 2 / (256 + 128) = 2 / 384 ≈ 0.00521
标准差 = √0.00521 ≈ 0.072

所以 w ~ N(0, 0.00521)
即大部分权重落在 [-0.144, +0.144] 之间（±2σ 范围，覆盖 95%）
```

​		**（2）Kaiming 初始化**：$ w \sim \mathcal{N}\left(0, \frac{2}{n_{i}}\right), $，适合 ReLU

​		

**8、偏置 b 一般怎么初始化？**

​		通常：初始化为 **0**，或小常数，或用对应方法一起处理

​		偏置不像权重那样敏感，全零一般没问题，因为权重已经随机，不会造成对称性问题。

​					注意：第二层卷积不仅看原始像素，而是在第一层提取到的特征基础上			继续提取更高层特征，比如从边缘组合成笔画结构、局部形状等。

​		**（5）第二次 Max Pooling**

​					再次 `2×2` 最大池化：8×8→4×4，通道数保持 `n2`，得到：4 × 4 × n2

​							- 用 ReLU 增加非线性

​							- 负责把空间特征映射到类别相关的高层表示

​					输出有 `n3 units`，即 `n3` 个神经元。

​		**（8）Dropout**

​					图里写了：(with dropout)

**4、卷积层**

​		（1）输入：彩色图像 `224 × 224 × 3`

​					表示一个 RGB 彩色图：宽224，高224，通道数3，对应 R / G / B 三个颜			色通道，可以把它理解成 **3 张 224×224 的二维图叠在一起**。

​		（2）一个 `3 × 3 × 3` 的 Filter / 卷积核

​					One 3 x 3 x 3 Filter，意思是这个滤波器的大小是：3 × 3 × 3，为什么第			三个维度也是 3？

​					因为输入有 3 个通道 RGB，所以卷积核也必须“深入”到每个通道里，分			别有：k₁ 对应 R 通道的 3×3 核、k₂ 对应 G 通道的 3×3 核、k₃ 对应 B 通道的 			3×3 核，也就是说，一个完整滤波器由 **3 个 3×3 的核**组成。

​					计算很直接：3×3×3=27，这是权重数量。再加上 1 个偏置 bias，				27+1=28，所以这个滤波器一共有 **28 个可训练参数**。

​					卷积核会在输入的 `224×224×3` 图像上滑动。

​					每一步：取当前局部区域，也是 `3×3×3`、和滤波器的 `3×3×3` 权重逐元			素相乘、把所有乘积加起来、再加偏置 `b`、得到一个标量值

​		（6）输出 Activation Map：`224 × 224 × 1`

​		（7）Max Pooling：最大池化

```
        ↓
加偏置，得到线性响应
        ↓
经过激活函数，得到 224×224×1 的激活图
        ↓
Max Pooling 下采样
        ↓
得到 112×112×1 的特征图
        ↓
作为下一个卷积块的输入
```

​		**（2）C1：第一层卷积层**

​					C1: feature maps 6@28x28：意思是 C1 层有 **6 张特征图**，每张大小是 			`28×28`。

​					通常 C1 使用 `5×5` 卷积核，步长为 1，不带 padding 或 valid 卷积：			32−5+1=28，所以输入 `32×32` 变成 `28×28`。

​					有 6 个卷积核，因此输出 6 个通道：6 @ 28×28，这一层主要提取低层			特征，比如边缘、线条方向、角点等。

​		**（3）S2：第一层下采样/池化层**

​					S2: f. maps 6@14x14：S2 是 subsampling，类似现在的池化层，常用			平均池化或最大池化。

​					特征图数量保持 6 张不变，但空间尺寸从：28×28 → 14×14，一般是 			`2×2` 下采样，所以宽高各减半。

​					**作用：**减少计算量、降低特征图尺寸、增强一定平移不变性、保留主要			响应

​		**（4）C3：第二层卷积层**

​					C3: f. maps 16@10x10：C3 输出 16 张特征图，每张 `10×10`。输入是 			`6@14x14`，用 `5×5` 卷积核：14−5+1=10，所以得到 `10×10`。通道数从 6 变			成 16。

​					这一层会在低层边缘/纹理基础上，组合出更复杂的结构，比如笔画			片段、局部形状。

​		**（5） S4：第二层下采样/池化层**

​					S4: f. maps 16@5x5S4: f. maps 16@5x5，S4 再次做 `2×2` 左右的下采			样：10×10 → 5×5，通道数保持 16 不变。所以输出是：16 @ 5×5

**3、AlexNet**

​		AlexNet 总共包含 **8 层可学习层**（5 个卷积层 + 3 个全连接层）。

​		**特征提取（左）**：通过多次“卷积 + 池化”操作，把图像一点点“压缩”并提取出复杂的特征。

​		**分类（右）**：红框标出的全连接层（Dense 2048/4096 维）和最后的 1000 维输出，负责把提取到的特征综合起来，判断图片到底属于哪一类。

​		**双 GPU 并行设计（上下分组）：**图二明显地展示了上下两路结构（如 48、128、192 通道上下对称）。这是因为在 2012 年，单个 GPU 显存装不下整个模型，所以作者把网络拆成两半，放在两块 NVIDIA GTX 580 GPU 上并行计算。上下两路在特定层才会进行信息交互。图中的 `48+48=96`、`128+128=256` 就是完整的通道数。

​			**第一层的大卷积核（`11×11`, Stride 4）：**图左侧标了 `11` 和 `Stride of 4`。因为输入是高分辨率的彩色大图（`224×224×3`），AlexNet 直接用很大的 `11×11` 卷积核、步长为 4 快速扫描图片。这样一下子就把图片尺寸降到了 `55×55`，同时抓取出最基础的边缘和颜色特征。

​			**尺寸逐渐缩小，通道逐渐增多：**观察图中的数字变化：空间尺寸从 `55 → 27 → 13`，越来越小；而通道数从 `48/128 → 192 → 128`（合计通道数递增），越来越厚。这符合 CNN 的直觉：**空间上不断下采样减少计算量，特征表达上不断变深变复杂**（从边缘 -> 纹理 -> 局部形状 -> 物体部件）。

​			**Local Response Normalization (LRN)：**第一张图黄色标签标出了 LRN。这是一种早期的归一化手段，模仿生物的“侧抑制”机制，让响应大的特征更突出，响应小的被抑制。不过在现在的网络中，它大多已被更强大的 Batch Normalization 取代了。

​			**巨大的全连接层与 Softmax：**红框部分手写了“2 fully connected layer with 4096-dim”（图中拆分成 2048 展示）。AlexNet 后面接了两个庞大的 4096 维全连接层，参数量巨大。最后通过 `Softmax` 输出 1000 个类别的概率，并借助 `Backpropagation`（反向传播）来更新所有参数。

4、AlexNet 核心特点

​		**使用 ReLU 激活函数**：放弃了传统的 Sigmoid/Tanh，改用 f(x)=max(0,x)。这解决了深层网络训练时的“梯度消失”问题，让模型收敛速度快了好几倍。

​		**最大池化（Max Pooling）**：图中多次出现，用它来降维，保留最显著的特征，同时增加模型对微小位移的鲁棒性。

​		**Dropout 防止过拟合**：虽然在图中没明确标出，但它在那两个巨大的全连接层中使用了 Dropout（随机关闭一部分神经元），强迫网络学习更鲁棒的特征，避免“死记硬背”训练数据。

​		**GPU 加速训练**：确立了用 GPU 做深度学习标准硬件的先河，让训练这种巨量参数的网络从“不可能”变为“几天就能训完”。

![image-20260726182022035](https://gitee.com/MaGL/typorapic/raw/master/20260726182022164.png)

**5、VGG**

​		VGG 是 2014 年提出的经典 CNN。接在 AlexNet 之后，证明“网络更深、结构更统一”可以提升图像分类效果。

​		**（1）全部/主要使用 `3×3` 卷积**

​		**（2）结构很统一：**

​				卷积层 → ReLU → 池化层 → 更多卷积层 → 全连接层。

​				图中可以看到 `conv1` 到 `conv5`，特征图尺寸逐步变小：112×112 → 			56×56 → 28×28 → 14×14 → 7×7

​				通道数逐步增加：64 → 128 → 256 → 512

​		**（3）Max Pooling 下采样**

​					通常用 `2×2` 池化，把空间尺寸减半。

​					减少计算量，同时保留主要特征。

​		**（4）后面有巨大的全连接层**

​					如图中 `fc6/fc7/fc8`，常见是：4096 → 4096 → 1000

​					这也是 VGG 参数量很大的原因。

​		统一用 `3×3` 卷积堆叠、结构清晰、效果比 AlexNet 好；但参数多、计算重，而且普通深层网络会出现“越深越差”的退化问题，促使了 ResNet 出现。

deeper is worse：普通 56 层网络比 20 层网络训练和测试误差都更高。这不是过拟合，而是深层网络难优化。

**6、ResNet（残差网络）**

​		**用“残差连接 / 跳跃连接”解决深层网络难训练、退化的问题**，让网络可以做得更深，同时性能更好。

​		**（1）为什么需要 ResNet？**

​					普通卷积网络叠得越深，理论上特征提取能力更强，但实际会出现：梯			度消失 / 梯度爆炸、准确率不升反降，叫**退化问题 degradation**、深层网络			反而不如浅层网络好训。

​				ResNet 通过**残差学习**解决这个问题。

​		**（2）核心思想：残差连接 shortcut / skip connection**

![image-20260726182119448](https://gitee.com/MaGL/typorapic/raw/master/20260726182119556.png)

**7、残差连接 shortcut / skip connection**

​		普通网络层学习的是：		$ H(x) $

​		ResNet 不直接学 H(x)，而是学习“残差”：$ F(x) = H(x) - x $

​		最终输出：		$ y = F(x) + x $

​		也就是把输入 x 直接加到输出上。

**8、Plain layers 普通网络层**

​		输入是 x，经过几层权重层/卷积层：x→weight layer→relu→weight layer

​		最后得到：  H(x)	， 再经过 ReLU 输出。

​		也就是说，普通网络试图让这几层**直接学习目标映射** H(x)。

​		问题是：网络很深时，直接学 H(x) 越来越难，容易出现梯度消失、退化，效果反而不好。

**9、Residual block 残差块**

​		weight layer，它们学习的是：F(x)

​		同时，输入 x 通过一条旁路直接传过去，图里标了 **identity**，意思是“恒等映射 / 原样传递”。

​		然后在加法节点把两路合并：	F(x) + x		再过 ReLU。

​		所以残差块的输出是：  $ y = F(x) + x $



![image-20260726182136755](https://gitee.com/MaGL/typorapic/raw/master/20260726182136890.png)

每一层不仅接前一层的输出，还把前面很多层的特征都“拼接/concat”起来用。

**10、在说什么？**

​		输入一张马的图像，经过：Input→Conv→Dense Block 1→Transition→Dense Block 2→Transition→Dense Block 3→Pooling/Linear→Prediction	，最终预测为 `"horse"`。

​		**Dense Block**：密集块，里面层与层之间密集连接。

​		**Transition layers**：过渡层，通常包含卷积和池化，用来压缩通道数、降低特征图尺寸。

​		最后通过池化、全连接/线性层做分类预测。

**11、DenseNet 密集连接卷积网络**

​		核心思想：密集连接

​		假设网络前几层输出分别是：$x_0, x_1, x_2, …, x_{l−1}$

​		那么第 l 层的输入不是只有 $x_{l−1}$，而是：$ x_l = H([x_0, x_1, ..., x_{l-1}]) $

​		其中：[ ] 表示在 channel 维度拼接、$H_l$ 通常是一个小卷积块（BN + ReLU + 1×1 + 3×3 之类）

​		所以层数越往后，**输入通道数越大**，因为不断把前面特征拼进来。

​		**(1) Dense Block（密集块）**

​				里面若干层，每层都和前面所有层连起来。

​				例如一个 block 有 4 层，增长率 growth rate = k：

​				第1层输入：k0 通道

​				第2层输入：k0 + k

​				第3层输入：k0 + 2k

​				第4层输入：k0 + 3k

​				输出再把这 4 层新特征拼上。

​		**(2) Transition Layer（过渡层）**

​				因为 concat 会让通道爆炸，所以用 transition 层来：

​				用 1×1 卷积降通道数，用 2×2 平均池化降分辨率

​				控制计算和显存。

​		**(3) 整体结构**

**12、DenseNet 和 ResNet 有什么区别？**

​		**Standard 普通网络：**每一层只把输出传给下一层：$ x_l = H(x_{l-1}) $，信息单链传递。

​		**ResNet：**当前层输出和前一层/输入做**逐元素相加**：$ x_l = H(x_{l-1}) + x_{l-1} $，重点是“加回来”，学残差。

​		**DenseNet：**当前层会接收前面所有层的特征，并做**通道拼接 concat**：$ x_l = H([x_0, x_1, ..., x_{l-1}]) $，这里 [...] 表示把前面特征图在通道维度拼起来。

| **网络**  | **连接方式** | **操作**                              |
| :-------- | :----------- | :------------------------------------ |
| Plain Net | 单层传单层   | $ x_l = H(x_{l-1}) $                  |
| ResNet    | 跳跃相加     | $ x_l = H(x_{l-1}) + x_{l-1} $        |
| DenseNet  | 密集拼接     | $ x_l = H([x_0, x_1, ..., x_{l-1}]) $ |

​		ResNet：**add**，信息融合但旧信息可能被覆盖	

​		DenseNet：**concat**，旧特征完整保留，层层复用

## 十三、NLP任务与循环神经网络

![image-20260726182154514](https://gitee.com/MaGL/typorapic/raw/master/20260726182154644.png)

![image-20260726182208899](https://gitee.com/MaGL/typorapic/raw/master/20260726182209003.png)

**1、RNN（Recurrent Neural Network，循环神经网络）**

​		**（1）左边：折叠后的 RNN**

​					左边画的是一个“压缩版”的 RNN：

​					x：输入
​					h：隐藏状态 / 记忆状态
​					o：输出
​					U：输入到隐藏层的权重					
​					W：隐藏层到隐藏层的循环权重
​					V：隐藏层到输出的权重

​					核心特点：同一个网络单元在不同时刻重复使用，并且会把上一时刻的					隐藏状态传给自己。

​					简单公式可以理解为：$ h_t = f(W h_{t-1} + U x_t + b) $，$ o_t = g(V h_t) $

​					$x_t$：第 t 个时间步的输入
​					$h_{t−1}$：上一时刻的记忆/状态
​					$h_t$：当前时刻更新后的状态
​					$o_t$：当前时刻的输出
​					$f,g$：激活函数，比如 tanh、ReLU、softmax 等

​		**（2）右边：Unfold / 时间展开**

​					图中写了 **Unfold**，意思是把循环结构按时间步展开。

​					右边变成：$ x^{(t-1)}, x^{(t)}, x^{(t+1)} $	，对应输入序列的不同时刻。

​					比如处理句子：I saw a cute cat

​					可以按词展开：$x^{(1)}$：I、$x^{(2)}$：saw、$x^{(3)}$：a、$x^{(4)}$：cute、$x^{(5)}$：cat
​			每个时刻都有一个：输入 $x^{(t)}$、隐藏状态 $h^{(t)}$、输出 $o^{(t)}$

​					绿色节点 h 之间用 W 连接，表示**上一时刻状态影响下一时刻状态**。

​		**（3）隐藏状态 h 是什么？**

​					可以把 h 理解为模型的“短期记忆”。比如在看句子：我 看到 一只 可爱			的 猫，当模型读到“可爱的”时，隐藏状态里应该记住前面有“一只”“看到”等			信息；读到“猫”时，结合上下文理解整句话。

​					所以：$x_t$：当前看到的新词/新信号、$h_{t−1}$：之前积累的信息、$h_t$：新旧			信息融合后的状态

​		**（4）RNN 适合什么数据？**

​				适合**有顺序关系**的数据：文本：单词/字符序列、语音：声波帧序列等

​		**（5）RNN 的问题**

​					**① 长期依赖困难：**如果上下文距离太远，早期信息容易被“忘掉”。

​					**② 梯度消失 / 梯度爆炸：**训练深层时间序列时，反向传播沿着很多时间					步往回传，梯度可能越来越小或越来越大。
​					所以后来出现了：LSTM、GRU，它们用门控机制改善记忆能力。



![image-20260726182222062](https://gitee.com/MaGL/typorapic/raw/master/20260726182222164.png)

**2、不同输入输出结构**

​		**（1）One to one：一对一**

​					输入：一段固定长度的文本特征 → 输出：一个标签

​					这和普通神经网络/普通前馈网络差不多：x→h→y

​					**例子：**
​					文本输入："这部电影太棒了"

​					处理：先通过某种方式（比如平均词向量）把这句话变成固定长度向量 					`[0.2, -0.5, 0.8, ...]`，输入网络，输出：`正面`

​					x = 句子向量 → h → y = 正面

​	![image-20260804095749365](https://gitee.com/MaGL/typorapic/raw/master/20260804095756522.png)

​		**（2）One to many：一对多**

​					输入：一个起始文本/条件 → 输出：一串文本

​					结构大概是：$ x \to h^{(1)} \to h^{(2)} \to h^{(3)} \to \ldots $，每个时间步都可以有输					出。

​					**例子：**
​					文本输入："从前有一座山"

​					RNN 按时间步生成：
​					第1步输出：`从`
​					第2步输出：`前`
​					第3步输出：`有`
​					第4步输出：`一`
​					……

​					x="从前有一座山" → h¹→o¹(从) → h²→o²(前) → ...

​	![image-20260804095825610](https://gitee.com/MaGL/typorapic/raw/master/20260804095825688.png)

​		**（3）Many to one：多对一**

​					输入：一串文本序列 → 输出：一个结果

​					比如输入多个词，只看最后一个隐藏状态做判断：										$ x^{(1)}, x^{(2)}, x^{(3)} \to h \to y $

​					**例子：**
​					文本输入（按词/字分时间步）："这 / 部 / 电 / ‌《影》 / 太 / 烂 / 了"

​					RNN 过程：
​					第1步读"这"，更新隐藏状态
​					第2步读"部"，结合上一步记忆
​					......
​					第7步读"了"，隐藏状态里已经积累了整句信息
​					只看最后一步隐藏状态 → 全连接层
​					输出：`负面`

​					x¹=这, x²=部, ..., x⁷=了 → h⁷ → y=负面

```
x¹=这  x²=部  x³=电  x⁴=影  x⁵=太  x⁆=棒  x⁷=了
 ↓     ↓     ↓     ↓     ↓     ↓     ↓
 RNN 隐藏状态不断更新
 ↓
最后时刻 h₇
 ↓
全连接 + softmax
 ↓
正面(0.92) / 负面(0.08)
```

​				所以“输出正面/负面”意思是：模型读完整个句子后，给出的情感类别判断				结果。

​	![image-20260804095853226](https://gitee.com/MaGL/typorapic/raw/master/20260804095853305.png)

​		**（4）Many to many：多对多，同步/等长**

​					输入：一串文本 → 输出：等长的一串标签

​									$ x^{(1)} \to y^{(1)}, \ x^{(2)} \to y^{(2)}, \ x^{(3)} \to y^{(3)} $

​					**例子：**
​					文本输入："我 / 爱 / 北京 / 天安门"

​					按字展开输入：我 爱 北 京 天 安 门

​					输出标签（每个字对应一个）：代词 动词 地名*起 地名*续 地名*续 地名*续 					地名_续，或者更简单的 NER 标签：O O B-LOC I-LOC I-LOC I-LOC 
​					I-LOC

	x¹=我 → y¹=O
	x²=爱 → y²=O
	x³=北 → y³=B-LOC
	x⁴=京 → y⁴=I-LOC
	...

​					每读一个字，立刻预测它的标签，输入输出长度一样。

​	![image-20260804095918172](https://gitee.com/MaGL/typorapic/raw/master/20260804095918257.png)

​		**（5）Many to many：多对多，异步/不等长**

​					输入：一串源语言文本 → 输出：一串目标语言文本（长度可不同）

​					**例子：**
​					输入英文（按词）：I / saw / a / cute / cat

​					Encoder RNN 读完整个句子，把意思压缩进最终隐藏状态；

​					Decoder RNN 拿着这个状态，逐词生成中文：
​					第1步输出：`我`
​					第2步输出：`看`
​					第3步输出：`到`
​					第4步输出：`一只`
​					第5步输出：`可爱的`
​					第6步输出：`猫`
​					输入 5 个 token，输出 6 个 token，长度不一样。

​					Encoder: x¹=I， x²=saw，... → h_final
​					Decoder: h_final → o¹=我 → o²=看 → o³=到 → ...

​					这就是 Transformer/GPT/翻译模型最早的那套 Seq2Seq 思路。

| :------------------- | :----------- | :--------------------- |
| One-to-one           | 句向量→情感  | 1句向量 → 1标签        |
| One-to-many          | 开头续写     | 1个prompt → 一段文本   |

## 十四、梯度消失与长短时记忆

![image-20260726182247202](https://gitee.com/MaGL/typorapic/raw/master/20260726182247305.png)

**1、梯度消失**

​	**（1）信息随时间衰减**

​				横轴是时间步：$t=0,1,2,3,4,5,6,…,t=100$

​				每个时间步有一列小圆点，可以理解为 RNN 隐藏状态 $s_t$ 中保存的“信息		成分”或“记忆内容”。

​				**直观含义：**

​						-每个时间步输入新的 $x_t$
​						-RNN 会把旧状态 $s_{t−1} $和新输入 $x_t$ 结合，得到新状态$s_t$
​						-但每次更新都会“覆盖 / 混合 / 稀释”之前的记忆
​						-所以很早以前的信息，比如 t=0 的输入，到 t=100 时几乎看不出来

​				图中不同颜色的小圆点可以看成不同时间步输入留下的“痕迹”。

​				**比如：**t=0 时有一些明显颜色，到 t=1,2,3 后，颜色不断被新信息混合，越		往后，早期颜色越淡，到 t=100 时，几乎只剩很弱、很模糊的痕迹。

​				这说明：RNN 的隐藏状态容量有限，而且状态不断更新，早期信息会			逐渐被冲刷掉。

​	**（2）为什么 RNN 会忘记很久以前的信息？**

​				简单 RNN 的更新大致可以写成：$ s_t = \tanh(Ws_{t-1} + Ux_t + b) $

​				**其中：**
​					$s_t$：第 t 个时间步的隐藏状态
​					$s_{t−1}$：上一个时间步的状态
​					$x_t$：当前输入
​					$W,U$：权重矩阵
​					$tanh$：非线性激活

​				可以看到，每个新状态都依赖于旧状态 $s_{t−1}$。如果要把 t=0 的信息传到 		t=100，它必须经过很多次这样的变换：$s_0→s_1→s_2→⋯→s_{100}$

​				每次都会乘权重、加新输入、经过激活函数。如果权重矩阵的特征值小于 		1，或者梯度相关因子小于 1，信息/梯度就会指数级衰减。

​	**（3）梯度消失到底是什么意思？**

​				假设我们在最后时刻或某个后续时刻计算损失，然后想更新早期参数，比		如影响 s0 的参数。

​				根据链式求导，梯度会经过很多时间步：

​									$ \frac{\partial E}{\partial s_0} = \frac{\partial E}{\partial s_T} \cdot \frac{\partial s_T}{\partial s_{T-1}} \cdot \frac{\partial s_{T-1}}{\partial s_{T-2}} \cdots \frac{\partial s_1}{\partial s_0} $

​				反向传播时要连乘很多雅可比矩阵：$ \frac{\partial s_t}{\partial s_{t-1}} $

​				如果这些导数因子多数都小于 1，那么连乘之后结果会指数级变小。

​				例如每次大概乘 0.8：		$0.8^{100}≈2×10^{−10}$	几乎为 0。

​				于是早期时间步得到的梯度非常小，参数几乎不更新，模型就“学不到”很		早之前输入和当前输出之间的关系。这就是 **梯度消失**。

**2、RNN 展开与时间步之间的梯度传播**

​		一个展开后的 RNN：$s_0→s_1→s_2→⋯→s_{100}$

​		每个时间步有：

​				输入 $x_0,x_1,x_2,x_3,x_4$
​				隐藏状态 $s_0,s_1,s_2,s_3,s_4$
​				输出/损失相关项 $E_0,E_1,E_2,E_3,E_4$

​		这里的 $E_t$ 可以理解成每个时间步的损失、误差或输出相关的能量/代价项。

​		箭头表示信息和梯度在时间步之间流动：
​				从左到右：前向传播，状态从上一时刻传到下一时刻
​				从右到左：反向传播，梯度从后面向前面传

​		图中标了一些偏导数，例如：$ \frac{\partial s_1}{\partial s_0}, \quad \frac{\partial s_2}{\partial s_1}, \quad \frac{\partial E_3}{\partial s_3} $

​		这些表示后一状态对前一状态的变化率，或者损失对某个状态的梯度。

**4、普通 RNN**

​		简单 RNN 单元：$ s_t = \tanh(Ws_{t-1} + Ux_t + b) $，也就是把上一时刻隐藏状态 $h_{t−1}$和当前输入 $x_t$，拼起来，经过线性变换后再用 $tanh $激活，得到新的隐藏状态 $h_t$。

​		新状态=tanh(旧状态+新输入)

**5、LSTM，长短时记忆网络**

​		LSTM 是为了解决 RNN 长期记忆问题而设计的。

​		它最关键的地方是：不仅有隐藏状态 $h_t$，还有一条“细胞状态” cell state，通常记为 $C_t$。

​		可以把 $$C_t$$ 理解成“主线记忆高速公路”，信息可以沿着它比较稳定地传递很多时间步。

​		图中标了几个门：Forget gate：遗忘门、Input gate：输入门、Output gate：输出门

​		还有 σ 和 tanh：
​				-σ 是 sigmoid，输出 0 到 1 之间的值，用来控制“开多少”
​				-tanh 输出 -1 到 1 之间的值，用来生成候选记忆内容
​				-圆圈里的 × 表示逐元素乘法，控制多少信息通过
​				-圆圈里的 + 表示逐元素加法，把新信息写进去

​		**（1）遗忘门 Forget gate**

​					决定从旧细胞状态 $C_{t−1}$ 中丢掉多少信息。$ f_t = \sigma(W_f[h_{t-1}, x_t] + b_f) $

​					如果 $f_t$接近 0，表示“忘掉”；如果接近 1，表示“保留”。

​					例如句子中主语从“他”变成“她”，模型可能通过遗忘门丢掉旧的性别/主			语相关信息。

​		**（2）输入门 Input gate**

​					决定当前新输入中有多少写入细胞状态。

​					通常有两部分：

​								$ i_t = \sigma(W_i[h_{t-1}, x_t] + b_i) $	$ \tilde{C}_t = \tanh(W_C[h_{t-1}, x_t] + b_C) $

​					其中：$i_t $ 控制“写多少”，$ \tilde{C}_t$是候选新记忆

​					然后更新细胞状态：$ C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t $ 这里 ⊙ 表示逐元素乘。

​					先通过遗忘门决定保留多少旧记忆，再通过输入门决定加入多少新记忆

​		**（3）输出门 Output gate**

​					决定细胞状态中哪些内容输出为隐藏状态 $h_t$。

​							$ o_t = \sigma(W_o[h_{t-1}, x_t] + b_o) $ 		$ h_t = o_t \odot \tanh(C_t) $

​					也就是说，LSTM 不是把所有记忆都直接暴露给输出，而是经过输出门			筛选。

​		**（4）为什么 LSTM 能缓解梯度消失？**

​					因为细胞状态更新里有类似：$ C_t = C_{t-1} \odot f_t + \text{新内容} $

​					这条路径上有加法连接，类似于“高速公路”。

​					反向传播时，梯度可以沿着这条路径较稳定地传回去，不必完全依赖一			连串矩阵连乘。所以它比普通 RNN 更能捕捉长期依赖。



**6、GRU，门控循环单元**

​		GRU 是 LSTM 的简化版。

​		它把 LSTM 的多个门和细胞状态合并得更紧凑。图中标了：Reset gate：重置门，Update gate：更新门

​		GRU 通常没有单独的细胞状态 $C_t$，而是只用隐藏状态 $h_t$。

​		**（1）更新门 Update gate**

​					类似 LSTM 中“遗忘 + 输入”的组合，决定保留多少旧状态、加入多少新			状态。

​									$ z_t = \sigma(W_z[h_{t-1}, x_t] + b_z) $

​					$z_t$ 接近 1 时，更多保留旧状态，接近 0 时，更多采用新内容。

​		**（2）重置门 Reset gate**

​					决定计算候选隐藏状态时，忽略多少过去的记忆。

​									$ r_t = \sigma(W_r[h_{t-1}, x_t] + b_r) $

​					候选隐藏状态大概是：$ \tilde{h}_t = \tanh(W[r_t \odot h_{t-1}, x_t] + b) $

​					然后最终更新：	$ h_t = (1 - z_t) \odot \tilde{h}_t + z_t \odot h_{t-1} $

| **对比** | **LSTM**                  | **GRU**                   |
| :------- | :------------------------ | :------------------------ |
| 门数量   | 3 个：遗忘、输入、输出    | 2 个：更新、重置          |
| 状态     | 隐藏状态 ht + 细胞状态 Ct | 只有隐藏状态 ht           |
| 参数     | 更多                      | 更少                      |
| 计算成本 | 较高                      | 较低                      |
| 效果     | 通常很强，尤其长序列      | 很多任务上接近 LSTM，更快 |

**7、BiLSTM，双向长短期记忆网络**

​		两个 LSTM 同时处理同一段序列，一个从左往右看，一个从右往左看，然后把两个方向得到的信息结合起来。

​		普通 LSTM / RNN 处理序列时，按时间顺序：$x_1→x_2→x_3→⋯→x_T$

​		所以在预测或表示某个位置 $x_t$ 时，它主要利用了：当前输入 $x_t$，之前的历史信息 $x_1,…,x_{t−1}$

​		但它看不到未来的信息 $x_{t+1},…,x_T$

​		比如在句子中：我今天很 __，因为考试考得很好。
​		如果填空“开心”，模型看到“因为考试考得很好”会很有帮助。
​		但如果单向 LSTM 从左到右处理，在填空白时可能还没看到后面的原因。

**8、BiLSTM 的核心思想：正向 + 反向**			

​	**（1）forward layer，正向层**

​				蓝色箭头从左到右：$x_{t−1}→x_t→x_{t+1}→⋯→x_T$

​				正向 LSTM 捕捉**过去到当前**的上下文。

​				例如在位置 xt，正向 LSTM 的输出包含了：$x_1,…,x_t$

​	**（2）backward layer，反向层**

​				绿色箭头从右到左：$x_T←⋯←x_{t+1}←x_t←x_{t−1}$

​				反向 LSTM 捕捉**未来到当前**的上下文。

​				在位置 $x_t$，反向 LSTM 的输出包含了：$x_{t+1},…,x_T$

​	**（3）每个时间步的输出怎么来？**

​				在每一个时间步 t，BiLSTM 通常会把正向隐藏状态和反向隐藏状态拼接起		来：$ h_t = [\overrightarrow{h_t}; \overleftarrow{h_t}] $

​				$\overrightarrow{h_t}$：正向 LSTM 在时刻 t 的隐藏状态
​				$\overleftarrow{h_t}$：反向 LSTM 在时刻 t 的隐藏状态
​				[⋅;⋅]：向量拼接 concat

​				有时也会做相加、加权平均等，但最常见是拼接。所以每个位置的表示同		时包含：左边上下文 + 右边上下文，也就是完整的双向上下文。

## 十五、编码器解码器、注意力机制

![image-20260726182349055](https://gitee.com/MaGL/typorapic/raw/master/20260726182349186.png)

**1、编码与解码**

​	**（1）Encoder RNN，编码器**

​				读取源句子：Я→видел→котю→на→мате→<eos>  逐个词处理。

​				编码器的作用是：把整个输入句子压缩成一个向量表示，或者说把输入序		列的信息汇总到最后一个隐藏状态中。

​				图中绿色箭头从编码器最后一个 RNN 单元指向解码器初始状态，并标		注：（Vector representation of the source - use it as initial decoder state）源		语言的向量表示，用它作为解码器的初始状态

​				也就是说，编码器最后时刻的隐藏状态 $h_T$ 或上下文向量 c 会被传给解码		器。

​	**（2）Decoder RNN，解码器**

​				解码器根据这个向量逐步生成目标句子：		

​								<bos>→I→saw→a→cat→on→a→mat→<eos>

​				<bos> 表示 beginning of sequence，序列开始符
​				<eos> 表示 end of sequence，序列结束符

​				解码器每一步预测下一个词，直到输出 `<eos>` 为止。

​	**（3）编码器具体在做什么？**

​				底部是源句子词嵌入：Input word embeddings

​				每个词先被映射成向量，比如：
​						“Я” → 向量 $x_1$
​						“видел” → 向量 $x_2$
​						“котю” → 向量 $x_3$
​						“на” → 向量 $x_4$
​						“мате” → 向量$x_5$
​						“<eos>” → 向量 $x_6$

​				然后 RNN/LSTM/GRU 逐个时间步处理：

​							$ h_1 = f(x_1, h_0) $
​							$ h_2 = f(x_2, h_1) $
​							$ h_3 = f(x_3, h_2) $
​							$ \cdots $
​							$ h_T = f(x_T, h_{T-1}) $

​					最终得到最后一个隐藏状态 $h_T$。

​					这个 hT 被认为包含了整个源句子的语义摘要，例如：这句话讲的是“我			看见一只猫在垫子上”。

​	**（4）解码器具体在做什么？**

​				解码器拿到编码器传来的向量后，用它初始化自己的隐藏状态：$s_0=h_T$

​				然后从 `<bos>` 开始生成。

​				每一步：
​						-输入当前词嵌入，比如第一步输入 `<bos>` 的嵌入
​						-结合解码器当前隐藏状态预测下一个词
​						-输出 “I”
​						-下一步把 “I” 作为输入，预测 “saw”
​						-再把 “saw” 作为输入，预测 “a”
​						-依此类推，直到预测出 `<eos>`

​	**（5）一个翻译过程例子**

​				源语言：Я видел котю на мате

​				编码器读完后得到一个语义向量，大概表示：“说话者看到一只猫在某个		垫子/席子上”

​				解码器根据这个意思逐步生成：
​							<bos> → 预测 I
​							I → 预测 saw
​							saw → 预测 a
​							a → 预测 cat
​							cat → 预测 on
​							on → 预测 a
​							a → 预测 mat
​							mat → 预测 <eos>

**2、带注意力机制的 Encoder-Decoder**

​		普通 Encoder-Decoder 的问题是：编码器要把整句话压成一个固定向量，解码时所有输出词都主要依赖这个向量。句子一长，信息容易丢。

​		**Attention 的核心是：**解码器每生成一个目标词时，不是只靠最后一个编码器向量，而是回头动态“看”源句子各个位置，给相关源词更高权重，再生成一个上下文向量送给解码器。

​		左边绿色部分：**Encoder 编码器**；右边红色部分：**Decoder 解码器**

​	**3、以翻译为例**

​			假设源句为：$x_1$=Я, $$x_2$$=видел, $x_3$=котю, $x_4$=на, $x_5$=мате, $x_6$=<eos>

​			目标句为：

​					$y_1$=<bos>，$y_2$=I， $y_3$=saw，$y_4$=a，
​					$y_5$=cat，$y_6$=on，$y_7$=a,，$y_8$=mat，$y_9$=<eos>

​		**（1）Step 0：编码阶段**

​					编码器逐个读入源词：Я→видел→котю→на→мате→<eos>		

​					每个时间步产生隐藏状态：$ s_1, s_2, s_3, s_4, s_5, s_6 $，这些状态保存了不同位			置的信息。

​					大致可以理解为：

​							$s_1$：和 “Я/I” 有关
​							$s_2$：和 “видел/saw” 有关
​							$s_3$：和 “котю/cat” 有关
​							$s_4$：和 “на/on” 有关
​							$s_5$：和 “мате/mat” 有关
​							$s_6$：句末/整体收尾信息

​		**（2）Step 1：解码器生成第一个词 “I”**

​					解码器初始输入通常是：<bos>

​					初始解码状态为$ h_1 $或 $h_0$，具体标号看实现。

​					现在要预测第一个真正输出词，也就是 “I”。

​					模型用当前解码状态去和所有编码器状态算分：
​										$\text{score}(h_{\text{step}=1}, s_1), \text{score}(h_{\text{step}=1}, s_2), \ldots$

​					假设得到：

| **源词** | **分数** |
| :------- | :------- |
| Я        | 高       |
| видел    | 中       |
| котю     | 低       |
| на       | 低       |
| мате     | 低       |
| <eos>    | 很低     |

​				softmax 后可能类似：α=[0.55,0.25,0.08,0.05,0.04,0.03]

​				然后加权求和：$ c_1 = 0.55s_1 + 0.25s_2 + 0.08s_3 + \cdots $，这个 $c_1$ 重点包含 		“Я/I” 的信息。

​				解码器结合自己当前状态、上一步输入/输出和注意力上下文 $c_1$,预测第一个词：P(y=I) 最高，所以输出：I



​		**（3）Step 2：生成 “saw”**

​					现在解码器已经生成/已知 “I”，下一步输入可能是 “I”，然后准备预测 			“saw”，当前解码状态更新为 $h_2$。

​					再次对所有编码器状态算注意力：$score(h_2,s_k)$

​					这时模型可能发现 “видел” 最相关，因为它对应 “saw”。；类似同上

​					$c_2=0.15s_1+0.60s_2+0.10s_3+…$，$c_2$重点包含 “видел/saw” 的上下			文。

​					解码器据此预测：saw



​		**（4）Step 3：生成 “a”**



​		**（5）Step 4：生成 “cat”**

​		**（6）Step 5：生成 “on”**

​		**（7）Step 6：再生成 “a”**

​		**（8）Step 7：生成 “mat”**

​		**（9）Step 8：生成 <eos>**

**4、带注意力机制的编解码器 的计算流程**

​		**算分（Scores）→ 归一化（Weights）→ 加权求和（Output）**

​	**（1）Attention input（注意力输入）**

​				**公式/符号**：s1,s2,...,sm（所有编码器状态） 和 ht（当前解码器状态）

​				$s_1,s_2,...,s_m$：编码器（Encoder）处理完源句子后，在每个时间步留下		的隐藏状态。以上面的俄语句子为例，m=6（加上结束符），那么$s_1$ 对应“Я”，$s_2$ 对应“видел”，$s_3$ 对应“котю”，以此类推。

​				$h_t$：解码器（Decoder）在当前第 t 步的隐藏状态。它代表了“目前已经生		成了哪些目标词”的进度信息。

​				**作用**：注意力机制就是要拿“当前解码器的进度 $h_t$”去和“源句所有位置的		信息 $s_k$”做匹配。

​	**（2）Attention scores（注意力分数）**

​				**公式**：$score(h_t,s_k),k=1..m$

​				**含义**："How relevant is source token k for target step t?"（源词 k 对当前		目标步 t 有多相关？）

​				这是一个**打分函数**。它接收当前的解码器状态 $h_t$ 和某一个编码器状态 		$s_k$，输出一个标量（一个实数分数）。

​				常见的打分函数有：点积（Dot product）、双线性/一般点积、加法注意		力（Additive/Bahdanau）

​				例子对应：假设解码器正准备生成第 4 个词 "cat"（即 t=4），此时 $h_4$包		含了 "I saw a" 的上下文。拿 $h_4$ 分别去和 $s_1,s_2,s_3... $算分，其中和 $s_3$（对			应“котю”）算出来的分数会特别高，因为语义最匹配。

​	**（3）Attention weights（注意力权重）**

​				**公式**：$ a_k^{(t)} = \frac{\exp(\text{score}(h_t, s_k))}{\sum_{i=1}^m \exp(\text{score}(h_t, s_i))}, \quad k = 1..m $

​				**含义**：*"attention weight for source token k at decoder step t"*（解码步 t 时		对源词 k 的注意力权重）

​				这一步就是对刚才算出的 **m 个原始分数做 Softmax 归一化**。

​				为什么要做 Softmax？把任意实数分数压缩到 (0,1) 区间，保证所有源词		位置的权重加起来正好等于 **1**（即 $\sum{a_k^{(t)}}=1$），形成一个概率分布。

​				**例子对应**：和“котю”算出的高分经过 exp 和归一化后，可能变成 0.70；而		其他不相关词（如“Я”、“видел”）的权重可能只有 0.05、0.10。这样就明确告		诉模型：“生成当前词时，70% 的信息应该来自源词的‘котю’这个位置”。

​	**（4）Attention output（注意力输出 / 上下文向量）**

​				**公式**：c(t)=a1(t)s1+a2(t)s2+⋯+am(t)sm=∑k=1mak(t)sk

​				**含义**：*"source context for decoder step t"*（为解码器第 t 步量身定制的源句		上下文）

​				这是对所有编码器状态 $s_k$ 的**加权求和（weighted sum）**。权重就是刚算		出来的 $a_k^{(t)}$。得到的结果 c(t) 是一个向量，叫做**上下文向量（context 			vector）**。它不是固定的，而是**随着解码步 t 动态变化**的。

​				**例子对应**：
​						生成 "saw" 时，$c^{(t)}$ 主要加权了 $s_2$（видел）
​						生成 "cat" 时，$c^{(t)}$主要加权了 $s_3$（котю）
​						生成 "mat" 时，$c^{(t)}$主要加权了 $s_5$（мате）
​				这个 $c^{(t)}$随后会送给解码器（通常与 $h_t$ 拼接或相加），帮助解码器预测		下一个词。

5、常见的打分函数

​		$h_t$：解码器在第 t 步的隐藏状态 / 查询向量 query
​		$s_k$：编码器第 k 个源词位置的状态 / 键-值来源 key-value source
​		score($h_t,s_k)$：一个标量分数，表示“当前要生成的目标位置 t 有多需要关注源词位置 k”

​	**（1）Dot-product 点积注意力**

​				**公式：**$ \text{score}(h_t, s_k) = h_t^T s_k $ ，也就是把解码器状态 ht 和编码器状态 sk 		做内积。

​				如果两个向量方向比较接近，内积大，说明相关性强。

​				比如解码器正要生成 “cat”，当前 ht 和源句中 “котю” 对应的 sk 语义/上下		文匹配度高，点积分数就高。

​				**优点：**计算简单、速度快、参数少

​				**缺点：**要求 ht 和 sk 维度通常一致，或者至少能直接做内积、表达能力较		弱、如果编码器/解码器状态空间差异较大，直接点积可能不够灵活

​	**（2）Bilinear 双线性 / 一般点积注意力**

​				**公式：**$ \text{score}(h_t, s_k) = h_t^T W s_k $，中间多了一个可学习矩阵 W。点积相当于 $ h_t^T I s_k $，也就是		用单位矩阵 I 做变换。

​				Bilinear 更一般化，它学习一个矩阵 W，把 sk 先投影到更适合和 ht 比较		的空间，再算相似度。

​				**优点：**比普通点积更灵活、可以处理/学习两个状态空间之间的映射关			系、参数和计算量仍然相对可控

​				**缺点：**表达能力还是偏“线性匹配”、不如 MLP 注意力复杂和非线性		

​	**（3）Multi-Layer Perceptron （MLP） 注意力**

​				**公式：**	$ \text{score}(h_t, s_k) = w_2^T \cdot \tanh(W_1[h_t; s_k]) $  ，这里 $[h_t;s_k]$表示把 $h_t$		和 $s_k$ 拼接起来。

​				**计算流程：**

​						把解码器状态 $h_t$ 和编码器状态 $s_k$ 拼接：$ [h_t; s_k] $

​						过一个线性变换 $W_1$：$ W_1[h_t; s_k] $

​						用 tanh 做非线性激活：$ \tanh(W_1[h_t; s_k]) $

​						再用一个向量 $w_2$ 投影成标量分数：$ w_2^T \tanh(W_1[h_t; s_k]) $

​				**优点：**表达能力强、早期 Seq2Seq + Attention 中非常经典、对 $h_t$ 和 $s_k$		的维度要求更灵活，因为拼接后可以投影

​				**缺点：**计算量比点积、双线性大、每个源-目标位置对都要过一个小网络/		投影，成本更高

| **方法**       | **公式**                       | **特点**                           |
| :------------- | :----------------------------- | :--------------------------------- |
| Dot-product    | $h_t^T s_k$                    | 最简单，快，但表达能力弱           |
| Bilinear       | $h_t^T W s_k$                  | 加可学习矩阵，更灵活               |
| MLP / Additive | $ w_2^T \tanh(W_1[h_t; s_k]) $ | 非线性，表达强，经典 Bahdanau 风格 |

**6、Bahdanau 模型**

**（1）双向编码器（Bidirectional Encoder）**

​			左侧的编码器不是单向读取源句的，而是使用了**双向 RNN**（如 					LSTM/GRU）。**"从头读一遍，再从尾读一遍"**

​			它会从左往右读一遍，再从右往左读一遍，然后把两个方向的状态拼接起来（Concatenate）。

​			**好处**：源句中的每个词（比如“котю”）的编码状态 $s_k$，都同时包含了它**前	后两边**的上下文信息，表征更丰富。

​		**为什么双向读？** 举个中文例子："**苹果**很好吃" vs "我用**苹果**手机"

​				同样一个词"苹果"，如果只从左往右读，你还不确定它的意思。但如果同		时知道它**后面**跟的是"好吃"还是"手机"，你就立刻明白了。

​				双向读，就是让每个词都拥有**前后两面的语境**。

**（2）加法/MLP 注意力打分（Additive / MLP Attention）**

​			左上角框图里展示的是 Bahdanau 模型最经典的**打分函数**：

**（3）动态上下文向量（Dynamic Context Vector $c^{(t)}$）**

​			**"每译一个词，重新看一眼原文"**

​			这是它解决传统 Seq2Seq 痛点的关键：

​					-传统模型只靠一个“固定长度”的向量硬扛整句话，长句必丢信息。
​					-Bahdanau 模型在解码的**每一步 t**，都会通过 Softmax 和加权求和，重			新算出一个专属的上下文向量 c(t)。
​					-也就是说，生成 "cat" 时看 "котю"，生成 "mat" 时看 "мате"，实现了**动			态回头查源句**。

```
俄语翻译英语：кот сидит на мате

翻译第1个词 "cat"  → 重点看 "кот"     → 得到上下文 c(1)
翻译第2个词 "sits" → 重点看 "сидит"   → 得到上下文 c(2)
翻译第3个词 "on"   → 重点看 "на"      → 得到上下文 c(3)
翻译第4个词 "the mat"→ 重点看 "мате"  → 得到上下文 c(4)
```

**（4）状态传递与软对齐（State Passing & Soft Alignment）**

​			右侧解码器在工作时，会把上一步的状态 $h_{t−1}$ 和刚算出的源上下文 $c_{(t)}$一	起传给下一步，帮助预测当前词的概率分布 $p^{(t)}$

​			同时，注意力权重天然地学到了源语言和目标语言之间的**软对齐（Soft 	Alignment）**关系，而且这种对齐是模型自己端到端训练出来的，不需要人工标注。

​			解码器在生成每个词时，会同时带上两个信息：
​					**我之前译了什么**（上一步的状态 $h_{t−1}$ ）
​					**原文里当前最该看哪**（上下文向量 c(t)）

| 译到    | 自动关注 |
| ------- | -------- |
| cat     | кот      |
| sits    | сидит    |
| on      | на       |
| the mat | мате     |

​				所谓**软对齐**，意思就是：模型自己学会了一个规律，这种"源词 ↔ 目标		词"的对应关系，**不是人工告诉模型的**，是它在训练中自己学会的。

```
传统 Seq2Seq:   整句话 → 压成一个纸条 → 盲翻（信息丢失）

Bahdanau:       整句话 → 每个词都有双向上下文
                            ↓
                翻译每一步 → 重新看一遍原文 → 找到最相关的词 → 再翻译
                翻译每一步 → 重新看一遍原文 → 找到最相关的词 → 再翻译
                翻译每一步 → 重新看一遍原文 → 找到最相关的词 → 再翻译
                
                
                
 我上一步的状态是 ht-1
       ↓
先用 ht-1 去查原文，算出上下文 c(t)    ← 先算注意力
       ↓
再把 ht-1 和 c(t) 一起喂进去，更新出 ht  ← 再更新状态
```

**7、Luong Model（Luong 注意力模型）**

```
我上一步的状态是 ht-1
       ↓
先根据 ht-1 更新出当前状态 ht           ← 先更新状态
       ↓
再用 ht 去查原文，算出上下文 c(t)        ← 再算注意力

用翻译官的话说：先凭借之前的经验往前走一步，然后带着"我现在的想法"去翻书确认。
```

​	**（1）打分函数：Bilinear / 乘法注意力（核心区别）**

​	**（2）解码流程：先算状态，再算注意力**

​				Luong 模型通常是**先更新解码器状态 $h_t$**，然后再用这个**当前状态 $h_t$** 去和		编码器状态算分、求上下文向量 $c^{(t)}$。

​				（对比 Bahdanau：Bahdanau 是用**上一步的状态 $h_{t−1}$** 提前算好 $c^{(t)}$，再		把$c^{(t)}$喂给解码器去更新状态）。

​	**（3）状态融合：拼接后过 tanh**

​				右上角的框图展示了得到上下文向量 $c^{(t)}$ 后如何预测：

​				**公式**：$ \tilde{h}_t = \tanh(W_c[h_t; c^{(t)}]) $

​				**重点**：将当前解码器状态 $h_t$和源上下文 $c^{(t)}$ **拼接（Concatenate）** 起		来，通过一个带 tanh 激活的线性层融合成$\tilde{h}_t$，最后用 $\tilde{h}_t$去计算输出概率 			$p^{(t)}$。

​				**第一步：拼接 [ht ; c(t)]**

​						把两个向量**首尾相接**拼成一个更长的向量。

​						打个比方：

```
ht  = "我想翻译成 cat，因为前面译的是..."
c(t) = "原文的 кот 在第二个位置，意思是猫"

拼起来 = 把两张纸条粘成一张长纸条
```

​				**第二步：过一个线性层 Wc**

​						拼接完的长向量太"粗糙"了，直接拿来用效果不好。

​						所以乘一个权重矩阵 Wc，相当于**对信息做一次筛选和压缩**——挑出				最有用的特征。

​						打个比方：粘好的长纸条 → 交给一个编辑 → 帮你提炼出关键信息

​				**第三步：过 tanh 激活函数**

​						tanh 的作用是把数值**压缩到 -1 到 1 之间**，让结果更稳定。

​						打个比方：编辑提炼完 → 再做个"标准化排版" → 输出整齐、可用的				终稿 $\tilde{h}_t$

​						这个 $\tilde{h}_t$就是融合了"我的想法"和"原文线索"的**最终状态**，用它去				预测下一个词的概率分布。
